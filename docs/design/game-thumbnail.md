# 게임 대표 썸네일

승인된 아크메이지(썬·콜)의 흉상과 대기 프레임을 외형 기준으로 내장 imagegen에서 제작했다. 기존 제목 ‘메이플 증강 디펜스’를 유지한다. 사용자 요청에 따라 결과 JPEG는 각각2,000,000바이트 미만이다. 게임 내 캐릭터 프레임은 변경하지 않았다.

| 결과물 | 규격 | 실제 크기 |
|---|---|---|
| assets/thumbnail/ice-lightning-mage-16x9.jpg | 1920×1080 | 1,302,665바이트 |
| assets/thumbnail/ice-lightning-mage-1x1.jpg | 1024×1024 | 851,202바이트 |

썬콜을 주인공으로 크게 배치하고 얼음·번개·마법서, 증강 카드3장, 공중섬 배경과 먼 검은 마법사 실루엣을 함께 구성했다. 얼굴·리본·회색 눈·청백색 머리와 검정/흰색 의상은 프로젝트의 캐릭터 자료를 참조했다. 원본 PNG는 생성 도구 저장소에 있고 프로젝트에는 납품 JPEG만 둔다. 기존 썸네일은 덮어쓰지 않았다. 월드 대표 이미지 교체·게시는 수행하지 않았다.

## 생성 지시

- 가로형: 승인 흉상과 대기 프레임을 얼굴·의상·신체비율의 기준으로 삼는다. 우측에 썬콜의 미소와 시전 자세를 크게, 좌측에 정확한 한글 제목과 증강 카드3장을 배치한다. 얼음빛과 금빛 제목을 대비시키고 배경은 공중섬·성·작은 보라색 적 실루엣으로 정리한다. UI·추가 문구·워터마크는 제외한다.
- 정사각형: 가로형 결과와 승인 흉상을 참조해 동일한 외형·색감·제목을 유지한다. 상단 제목, 우측 아래 캐릭터, 좌측 아래 증강 카드로 다시 구성한다. 얼굴과 제목을 자르거나 이미지를 늘리지 않는다.
- 내보내기: JPEG quality96, 4:4:4, 규격별 리사이즈 후 실제 바이트 수를 검사했다.
