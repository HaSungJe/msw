# 비숍 기준 캐릭터 제작 프롬프트

현재 비숍의 원화·대기·스킬 프레임·흉상을 모든 직업의 **공통 그림체·인체비율·결과물 구성** 기준으로 사용한다. 제작 규칙은 [유닛 원화·프레임](../unit-art.md), 비숍 자산 목록은 [비숍 적용 기록](bishop-motion.md)을 따른다. 이 문서는 그대로 복사하여 변수만 채우는 생성 프롬프트다.

## 실제 이미지 첨부가 필수

경로를 프롬프트에 적는 것만으로 이미지가 전달되지는 않는다. 아래 파일을 직접 열어 확인하고 이미지 생성 도구의 참조 이미지로 전달한다. 작업 기록에 사용한 경로와 SHA256을 남겨 기준 파일이 바뀌었는지 구분한다. 반려 시안·과거 백업·썬콜을 공통 기준으로 대신 사용하지 않는다.

| 용도 | 기준 이미지 | 역할 |
|---|---|---|
| 원화 | `assets/design/characters/bishop/concept.png` | 완성도·선·채색·캐릭터 구성 |
| 대기 | `assets/design/characters/bishop/frames/wait/motion01.png` | 서 있는 인체비율·편안한 자세·표시 크기 |
| 스킬 | `assets/design/characters/bishop/frames/angel-ray/motion01.png`~`motion05.png` | 같은 인물의 동작 간 비율·그림체 유지 |
| 흉상 | `assets/design/characters/bishop/portrait.png` | 얼굴·상체 구도·얼굴 비중·마감 |

한 번에 모든 이미지를 넣기보다 목적에 맞게 고른다. 원화에는 비숍 원화+대기, 대기에는 비숍 대기+대상 직업 승인 원화, 스킬에는 비숍 엔젤레이의 유사 자세+대상 승인 원화+대상 승인 대기, 흉상에는 비숍 흉상+대상 승인 원화를 첨부한다. 참조 이미지 번호와 역할을 실제 전달 순서에 맞춰 프롬프트 맨 앞에 명시한다.

비숍의 얼굴 생김새·머리색·성직자 의상·지팡이를 다른 직업에 복제하지 않는다. **비숍과 같은 작화 방식과 신체 구조 안에 각 직업의 정체성을 담는다.** 이미 승인된 직업은 얼굴·색·의상·무기를 보존하고, 공통 그림체와 충돌하는 큰 재디자인은 먼저 원화로 보여 준다.

## 모든 생성에 붙이는 공통 프롬프트

```text
첨부한 비숍 이미지와 같은 게임에 등장하는 {직업명} 캐릭터를 그린다.
비숍 이미지는 작화·인체비율의 우선 기준이고, 대상 직업의 승인 원화는 외모·색·의상·무기의 우선 기준이다. 두 역할을 섞지 않는다.

작화: 비숍과 같은 매끈하고 섬세한 2D SD 일러스트. 또렷한 외곽선과 얇고 정돈된 내부 선, 부드럽되 형태가 읽히는 명암, 절제된 윤기, 선명한 눈동자와 작은 입. 같은 크기로 놓았을 때 비숍과 선 굵기·채색 밀도·명암의 강도가 어울리게 한다. 얼굴은 짧고 둥글게, 목은 짧게, 어깨와 몸통은 작고 단정하게 표현한다.

인체비율: 현재 비숍 대기와 엔젤레이의 머리/몸통/팔다리 관계를 그대로 따른다. 중립 선 자세는 모자·장식·머리카락 끝을 제외하고 정수리~턱의 머리 길이 약 1에 정수리~발바닥 약 2.3인 비율을 지향한다. 머리를 줄이거나 허벅지·종아리·부츠를 늘려 성인 체형으로 만들지 않는다. 손과 발도 비숍과 같은 작은 크기다. 무릎을 굽히면 키가 낮아질 뿐 머리 크기나 뼈 길이는 바뀌지 않는다. 긴 망토·무기·머리카락 때문에 신체를 축소하지 않는다.

직업 정체성: {고유 외모}. {의상과 장식}. {무기와 소품}. 고정 색상은 {고정 색상}. 표정 컨셉은 {표정 컨셉}. 비숍의 베이지 머리·금빛 눈·성직자 복장을 복사하지 않는다. 모든 직업에게 미소를 강제하지 않는다.

동일 인물 유지: 머리 크기·얼굴형·눈 간격·눈동자·머리 길이·몸통·팔·다리·신발 길이와 의상 부품·장식 위치·무기 형태를 모든 결과에서 유지한다. 자세와 지정한 표정만 바꾼다. 액션이 커져도 다리를 길게 하거나 몸매를 성숙하게 바꾸지 않는다.

마감: 실제 투명 배경, 깨끗한 알파 경계, 글자·숫자·테두리·격자·로고·바닥 그림자 없음. 머리카락·모자·손발·무기 끝까지 잘리지 않도록 여백 확보. 작은 게임 표시 크기에서도 얼굴과 자세가 읽히게 한다.
```

## 원화용 추가 프롬프트

```text
완성 원화 1장을 만든다. 한 캐릭터의 전신을 보여 준다.
비숍 원화의 밀도와 마감을 따르고, 전신 비율은 비숍 대기·엔젤레이 기준으로 맞춘다. {직업명}의 소품과 무기를 보여 주되 신체 윤곽과 짧은 다리가 읽히게 한다. {표정 컨셉}을 얼굴에 반영한다. 과도한 원근·극단적인 도약·신체를 가리는 대형 이펙트는 피한다.
사용자가 이 원화를 승인하면 같은 얼굴·비율·의상으로 대기·공격·흉상을 제작할 수 있는 명확한 디자인이어야 한다.
```

원화 승인 전에는 전체 프레임을 생성하지 않는다. 기존 승인 원화가 있으면 재승인을 반복해서 요구하지 않고 승인 범위 안에서 진행한다.

## 대기용 추가 프롬프트

```text
대상 직업의 승인 원화와 정확히 같은 캐릭터로 대기 프레임 3장을 만든다.
비숍 대기처럼 허리를 편 편안한 선 자세. 발 간격은 좁고 안정적이며, 무기는 직업에 맞게 자연스럽게 내리거나 가볍게 받친다. 공격을 겨눈 자세·크게 벌린 다리·과장된 골반 꺾임은 사용하지 않는다. 기본 표정은 {표정 컨셉}.
01 기준 자세 / 02 작은 들숨과 옷자락 변화 / 03 작은 날숨과 머리카락 변화.
발바닥 접점·머리 크기·얼굴·의상·무기 길이·색을 고정한다. 화면 전체를 흔들거나 확대하지 않는다. 최종 재생은 01→02→01→03이며 연결부가 자연스러워야 한다.
```

최종 PNG는 576×576, 발 중심 (288,512). 여러 장을 한 시트로 만들면 셀 사이 여백을 충분히 두고 이웃 칸의 머리카락·무기가 침범하지 않게 한다. 한 자세부터 비숍과 비교해 통과한 뒤 나머지를 만든다.

## 스킬용 추가 프롬프트

```text
대상 직업의 승인 원화·대기와 정확히 같은 캐릭터로 {스킬명}의 연결 프레임 {장수}장을 만든다.
비숍 엔젤레이처럼 공격 중에도 얼굴과 머리 크기, 짧은 몸통·팔다리, 선과 채색이 유지되어야 한다. 비숍의 지팡이 자세를 복사하지 말고 {직업명}의 무기에 맞게 아래 동작을 수행한다.
동작 순서: {프레임마다 자세를 구체적으로 나열}.
손·손잡이 접촉을 유지하고 무기와 손이 분리되거나 추가되지 않게 한다. 보는 방향은 {방향}으로 고정한다. 고정 발은 같은 위치에, 실제로 움직이는 발은 지정한 궤적에 놓는다. 앉거나 일어날 때 망토 끝을 발바닥으로 오인하지 않는다.
타격·시전 시간: {실제 타격 시점과 전체 길이}. 준비→타격→후속 동작→대기 복귀가 이 순서와 시간에 맞게 이어져야 한다. 손·어깨·몸통·무기의 중간 자세를 직접 그린다. 같은 이미지를 단순 이동·회전·확대하거나 흐리게 섞어서 연결 프레임을 대신하지 않는다.
캐릭터 PNG에 들어갈 효과: {필요한 효과 또는 없음}. 게임에서 별도로 재생하는 공격 이펙트는 캐릭터 그림에 중복해서 그리지 않는다.
```

최종 PNG는 704×704, 기준 발 중심 (352,640), 대기와 같은 신체 표시 배율. 프레임 수는 실제 동작에 맞춘다. 비숍이 5장이라는 이유로 연사·루프·복잡한 스킬까지 무조건 5장에 압축하지 않는다.

## 흉상용 추가 프롬프트

```text
대상 직업의 승인 원화·대기와 정확히 같은 캐릭터로 선택창·상세정보용 흉상 1장을 만든다.
첨부한 비숍 portrait.png와 같은 얼굴 비중과 얼굴~어깨~가슴 윗부분 구도, 같은 선·명암·눈 표현·마감을 사용한다. 전투용 작은 머리를 단순 확대해 흐리게 만들지 않는다. 얼굴형·눈매·머리색·의상·장식·{표정 컨셉}을 승인 원화 그대로 유지한다. 머리 위 핵심 장식과 양옆 머리카락은 충분히 보이게 하고, 무기나 이펙트가 얼굴을 가리지 않게 한다. 실제 투명 배경이며 얼굴이 시각적 중심이다.
```

최종 `portrait.png`는 512×512. 영입창·상세정보의 실제 크기에서도 잘리지 않고 얼굴이 읽히는지 확인한다.

## 통과 기준 — 안 맞으면 전체 제작 전에 수정

- 참조 파일을 실제로 열고 생성 도구에 첨부했는가? 경로만 써 놓고 첨부하지 않았다면 미준수다.
- 비숍 대기와 대상 대기를 같은 신체 배율·발 기준선으로 나란히 비교했는가? 먼저 머리 길이를 맞춘 뒤 몸통·팔·다리·부츠가 길어지지 않았는지 본다. 모자·무기 포함 바운딩박스로 키를 맞추지 않는다.
- 비숍의 약 2.3등신은 육안 근사다. 숫자만 맞추고 다리나 얼굴이 다른 결과를 통과시키지 않는다. 대기 기준 약 338px 신장/147px 머리/72px 의상 아래 다리는 비교 보조값이며 의상 밑단을 해부학적 골반으로 간주하지 않는다.
- 원화·대기·스킬·흉상에서 같은 캐릭터로 보이는가? 눈 간격·얼굴형·머리 크기·옷 부품·무기·색이 달라지면 수정한다. 표정은 해당 직업의 승인 컨셉을 따른다.
- 전체 프레임 비교와 실제 표시 배율 재생에서 발 미끄러짐·신체 팽창·긴 부츠·잘린 머리카락·이웃 프레임 잔여물이 없는가?
- 비율이 틀렸다면 신체를 올바르게 재작화한다. 전체 이미지를 작게 만드는 것만으로 다리 비율 문제가 해결됐다고 하지 않는다.

작업 기록에는 참조 파일·해시, 완성 프롬프트, 같은 발 기준 비교, 프레임 순서·시간을 남긴다. 결과물 폴더에는 `concept.png`, `portrait.png`, `frames/wait/motionNN.png`, `frames/<english-skill-name>/motionNN.png`만 둔다. 공통 프롬프트가 결과 일관성을 자동 보장하지 않으므로 비교 검수를 생략하지 않는다.
