# 아크메이지(불·독) 외형·프레임

상태: **게임 적용·사용자 재생 확인 완료**. 승인된 원화를 바탕으로 만든 전용 PNG를 기본 아바타 대신 표시한다. 포이즌 리전과 도트 퍼니셔의 동작을 새로 제작했고, 사용자가 재생 후 “괜찮네. 이대로 적용하자”로 확정했다.

## 고정 컨셉

- 백금빛 가운데 가르마 웨이브와 검정 리본으로 묶은 두 갈래 머리, 금빛 눈, 차분하고 자신감 있는 옅은 미소.
- 검정·금색 자수 망토, 흰 높은 칼라와 금장 상의, 검정 주름치마와 흰 레이스, 짧은 검정 스타킹 다리, 갈색 금장 부츠.
- 호박색 구체가 박힌 금색 스태프와 떠 있는 진홍색 마법서. 대형 화염·독안개·구체는 기존 게임 이펙트가 담당한다.
- 대기의 얼굴·인체비율·색감·의상을 기준으로 시전 프레임을 구성한다. 이미지 전체를 같은 종횡비로 축소하고 발 기준점을 맞춘다. 신체 일부를 따로 늘이거나 재채색하지 않는다.

## 동작과 시간

이번 두 동작은 기존 공통 아바타 액션을 복제하지 않고 사용자가 지정한 스킬별 자세로 교체했다. 대기는 흔들림 없는 정지 1장이다.

| 스킬·선택 키 | motion01 | motion02 | motion03 | 합계 |
|---|---|---|---|---|
| 포이즌 리전 · poisonRegion | 지팡이를 수직으로 들어 올림, 0.40초 | 무릎을 살짝 굽혀 지팡이 끝을 바닥에 찍음, 0.45초 | 지팡이를 짚은 채 자세 회복, 0.35초 | 1.20초 |
| 도트 퍼니셔 · dotPunisher | 지팡이를 한쪽 위로 들어 올림, 0.35초 | 머리 위를 지나는 원호로 휘두름, 0.40초 | 반대편 앞·아래로 휘두른 마무리, 0.45초 | 1.20초 |

- 포이즌 리전: 시전 0.40초에 독 폭발·시전음·구역 독안개를 시작해 내려찍는 자세와 맞춘다. 독 지대 지속 10초 전체를 시전 자세로 유지하지 않는다.
- 도트 퍼니셔: 시전 0.35초부터 구체와 시전 클립을 표시한다. 구체 대기 시간을 1.20초에서 0.85초로 줄여 기존 시전 기준 발사·피해 판정 시각을 유지한다. 초월도 같은 캐릭터 프레임을 사용한다.
- 스킬 피해량·쿨타임·대상 선택은 바꾸지 않았다. 패시브 공격 프레임은 만들지 않는다.

## 제작 방식

내장 imagegen에 승인된 대기 이미지를 참조로 제공했다. 생성 지시는 얼굴·금빛 눈·백금발·검정/금색 의상·스태프·매끈한 SD 그림체를 유지하고, 포이즌 리전의 들어 올리기→바닥 찍기→회복, 도트 퍼니셔의 한쪽 위→머리 위→반대편 휘두르기를 각각 투명 배경 3장으로 만드는 내용이다. 대형 스킬 효과·문자·배경은 제외했다. 출력 후 Sharp로 전체 비례 축소와 투명 캔버스 배치만 수행하고 발 위치와 표시 크기를 비교했다.

## 게임 연결

`RtsJobTableLogic.HasMageSkin(jobId)`가 il/fp를 구분하며, 프레임·시간·흉상 조회에도 jobId를 전달한다. `SpawnUnit`은 두 직업에 기본 AvatarRenderer·CostumeManager를 생성하지 않는다. 썬콜의 기존 프레임과 시간표는 유지한다.

## 검증

- Maker stop → refresh → save → play 후 빌드 오류 0, 기존 경고 8을 확인했다.
- 실제 전투 중 두 스킬의 motion01→02→03 RUID 및 대기 복귀를 클라이언트 로그로 확인했다. 런타임 오류는 없었다. 사용자가 같은 Play에서 두 동작을 확인하고 채택했다.
- 초기 연결 검증에서 불·독/썬콜 동시 표시와 기본 아바타 미생성, 선택·상세 흉상을 확인했다. 썬콜 블리자드의 기존 3프레임과 3초 뒤 대기 복귀도 검증했다.
- 상세정보 생성 중 메소 동기화가 겹치는 재진입은 Render 보호로 처리했다. 모션 확인용 30레벨 불·독은 Play 세션에만 배치했으며 영구 저장하지 않았다.
