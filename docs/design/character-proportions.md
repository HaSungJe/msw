# 원화 유지 + 현재 비숍 모션 비율

현재 공통 제작 기준은 비숍의 원화·프레임·흉상 구성, 그림체와 인체비율이다. [공통 프롬프트](unit-art-prompts.md)와 [유닛 원화 규칙](../unit-art.md)을 따른다. 각 직업의 승인 외모·색·의상·무기·표정 컨셉은 보존한다. 아래는 앞선 비율 보정 작업 이력이며, 비숍을 비율만 참고하도록 제한하는 규칙이 아니다. 썬콜 2등신 시안과 비숍의 얼굴·의상을 다른 직업에 복제한 시안은 채택하지 않는다.

| 직업 | 콘셉트 | 모션 PNG |
|---|---|---|
| 비숍 | 기존 외형 유지, 현재 모션 비율로 재조정 | 기준인 기존 18장 유지 |
| 썬콜 | 파란 머리·원래 눈매·결정 디테일 유지 | 대기3·체인5·블리자드5 보정 |
| 불독 | 기존 외형으로 약2.3등신 재조정 | 기존 약2.28등신이 기준에 가까워13장 유지 |
| 히어로 | 승인 원화의 얼굴·갑옷·검 유지, 약2.3등신 | 대기01은 확정 원화 정렬, 대기02·03 및 공격15장 재작화. 새18개 RUID 연결·사용자 확인 완료 |

히어로 모션은 후속 요청으로 실제 신체 비율을 재작화했다. 이전 전체 등비 축소18장은 교체 전 이력이다. 대기에는 검을 유지하고 공격15장은 개인 검 없는 자세를 유지한다. 흉상은 원래 얼굴 보존에 따라 유지했다. 현재 비숍 wait/motion01.png가 인체비율 원본이며 이전2등신 비숍 콘셉트는 기준으로 사용하지 않는다.

## 파일과 검증

각 직업 assets/design/characters/<id>/concept.png가 최신 원화다. 대기576×576·발(288,512), 공격704×704·발(352,640) 규격과 재생 순서·시간을 유지했다. 비숍 기준값은 육안 근사: 정수리174, 턱321, 발512. 모자·리본·무기는 제외하며 굽힘·원근을 감안한다. 픽셀 단위로 모두 동일하다는 뜻은 아니다.

내장 image_gen으로 원화와 썬콜 프레임을 편집했다. Sharp는 전체 등비 축소·투명 캔버스·발 정렬·검수 시트에만 사용했다. 비숍18장 불변을 SHA256으로 확인했다. 생성 프롬프트는 .beaver/output/bishop-standard/revisions/*.json 및 *concept*.json에 기록했다. 원본 백업은 originals/에 있다.

## 이전 적용 이력

로컬 PNG 저장·시트 검수 완료. 변경31장 새 RUID 업로드·연결 완료. Maker 새로고침·재시작 및 새 리소스31/31 로딩 확인. 연결/시간표 오류0, 빌드/실행 오류0. 이전 .beaver/output/character-proportions/의2등신 비교는 반려 기록이며 기준이 아니다.


검증 근거: .beaver/output/bishop-standard/runtime-verification.json. [BISHOP_RATIO] loaded=31/31 mappings_or_timing_errors=0 로그 확인. 스킬 전체 자세의 인게임 시각 재생 검수는 별도이며 이번 확인은 리소스 로딩·연결·시간표까지다. 히어로 본체 축소에 맞춰 검의 손 부착 좌표에도338/394를 적용했고, 불꽃 월드 크기2.0은 유지했다. Maker는 Play 상태로 돌려놓았다.

## 현재 히어로 적용

확정 콘셉트와 비숍 프레임을 실제 첨부하여 대기02·03 및 공격15장을 내장 imagegen으로 재작화했다. 대기01은 확정 콘셉트에서 정렬했다. 머리 길이 약147px와 발 기준을 맞췄고 최종 손 좌표7개를 다시 측정해 이전338/394 보정을 제거했다. 새18개 RUID 업로드·연결과 Maker refresh/save/play를 완료했다. `[HERO_RATIO] loaded=18/18 mappings_or_timing_errors=0`, `[HERO_QA] ready=true sword=14` 확인. 빌드·실행 오류0. 사용자가 Maker 확인 후 “이정도면 됬어”로 승인하여 추가 재생 시험은 종료했다. 자동 관측으로 모든 공격 프레임·좌우 반전을 확인했다는 뜻은 아니다.

현재 연결표는 [히어로 모션](hero-motion.md)과 `.beaver/output/hero-bishop-motion/resource-manifest.json`이다. [현재 모션 미리보기](../../.beaver/output/hero-bishop-motion/preview.html).

후속 인레이지 확인 완료: 실제 PlayCast로 왼쪽7/7·오른쪽7/7 프레임, 불꽃 표시, 개인 검 중복0을 관측했다. 카메라 중앙 아래에서 반복 재생한 결과를 사용자가 확인하고 최종 확정했다. 임시 검증 유닛·효과는 제거했다.
