## 바닥 타일 제작 및 점검

`*-floor-source.png`는 생성된 색·질감 원본, `*-floor-256.png`는 256px 축소 초안이다. 생성기는 완전한 주기 경계를 보장하지 못한다. 256px 초안의 좌우/상하 RGB 가장자리 평균 차이(0~255): 엘리니아 12.5/7.7, 페리온 2.9/2.8, 커닝 2.5/4.9, 리스 3.9/4.1. 엘리니아·페리온 초안은 가장자리 일부 알파도 255 미만이다.

1. 원본 질감을 기준으로 256×256 **완전 불투명·반복 가능한** 타일을 만든다. 구현 방법은 기존 `gen-henesys-floor.js` 방식의 절차 생성이나, 이미지 경계를 맞추는 결정적 보정 중 적합한 쪽을 사용한다. 위 팔레트와 원본 질감의 세부 밀도를 유지한다. 엘리니아의 큰 잎무늬는 전투 칸에서 반복 패턴이 도드라지지 않도록 크기·명도를 낮춘다.
2. 각 타일을 3×3으로 반복한 미리보기에서 양 방향 이음새·강한 반복무늬가 보이지 않는지 확인한다. 알파 255, 256×256 PNG를 확인한 뒤 **새 리소스**로 업로드한다.
3. `CaveFloorTileSet.tileset`에 새 Name 4개를 추가하고 `floorTile`에 연결한다. 기존 헤네시스 타일 데이터는 교체하지 않는다. 바닥 변형은 우선 비운다(`floorVariants={}`, `variantRatio=0`).

## 트랙 판 제작

- `tools/gen-track-grid.js`를 테마별 색·재료 프리셋으로 확장해 1280×1040 투명 트랙 판 5종(헤네시스는 기존 판 유지 가능)을 만든다. 이미지생성 시안의 길 모양을 직접 쓰지 않는다.
- `SEQ`, `PATH`, `isBoss`, 16×13 칸 수·80px 칸 크기·77 경로 칸, 설치 칸·보스 영역, 진행/되돌리기 화살표의 의미는 유지한다. 길 표면과 연석·발판 선색만 바꾼다.
- 표의 길 재료를 적용한다. 엘리니아는 뿌리가 돌 가장자리에 조금 닿고, 페리온은 밝은 사암 덩어리, 커닝은 도시 벽돌, 리스는 목재 판자와 항구석의 교차다. 길과 바닥의 밝기 차이가 플레이 화면에서 충분해야 한다. 리스 길은 백색 돌만 사용하면 모래 바닥에 묻히므로 중간색 목재 비중을 높인다.
- 새 판 RUID마다 `gridTint=Color(1,1,1,1)`로 지정한다. S 초록·E 붉은 아이콘과 진행 점선은 지금처럼 일관되게 유지한다.

## 프리셋·썸네일 연결

- 400×240 썸네일 5장을 **각각 새 스프라이트 RUID**로 업로드해 `RtsThemeLogic.GetPresets().thumb`에 넣는다. 썸네일은 프로필 카드 250×200뿐 아니라 상자 104×48, 유저 카드 280×56에도 쓰인다. 작은 두 뷰의 읽기 대비를 확인하고, 닉네임 위 어두운 막은 유지한다.
- 장식 4종을 새 스프라이트 RUID로 업로드해 각 테마의 `decor`에 넣는다. 기본 헤네시스 장식은 그대로. 위치는 위 표에서 시작한다.
- `key`(`henesys`·`ellinia`·`perion`·`kerning`·`lith`), `free=true`, 저장 키, RPC, 서버 적용 순서, 구역별 적용 구조는 변경하지 않는다. 자세한 경계는 `docs/theme-presets.md` 5절.
- 업로드 RUID, 새 타일 Name, 생성한 최종 바닥·트랙 PNG 경로를 `assets/textures/README.md`에 기록한다. 이 가이드 상태는 Maker 검증 후 `구현됨`으로 바꾼다.

## 검증

1. 사용자가 Play 중인 경우 세션을 임의로 끊지 않는다. 재시작 가능해지면 `maker_stop → maker_refresh_workspace → maker_save → maker_play` 순으로 로드한다.
2. 빌드/일반 로그의 오류를 본다. 프로필에서 5종을 순서대로 골라 내 구역만 바닥·트랙·장식이 바뀌는지 확인한다. 다른 유저 구역은 그대로여야 한다.
3. 엘리니아 거목과 커닝 공사장 표식이 카메라 안에서 즉시 보이는지, 리스 범선·페리온 절벽이 전투판과 겹치지 않는지 캡처로 본다. 유닛·몹·설치 칸과 길의 대비, 썸네일 3개 표시 크기도 본다.
4. 통과 후 `docs/ui-screens.md`·`docs/theme-presets.md` 상태표를 갱신한다. 커밋·푸시는 사용자 명시 승인 전에는 하지 않는다.

## 이미지 생성 기록

내장 `image_gen`으로 제작. 거목·절벽 마을·공사장·범선은 확정된 각각의 마을 시안을 **화풍 참고**로 사용한 투명 컷아웃이다. 바닥은 각 시안의 팔레트를 참고한 탑뷰 질감이며, 리스 바닥 최종 원본은 페리온 흙 질감을 옅은 석회암 모래로 바꾸는 편집이다. 썸네일은 승인된 시안을 400×240으로 축소했다. 자세한 콘셉트 근거와 원작 마을 참고 링크는 `assets/theme-concepts/README.md`.
