# 캐릭터 7종 확정 원화

2026-09-27 사용자 요청으로 아래 7종을 후속 캐릭터 디자인 작업의 기준 원화로 저장했다. 다크나이트는 **비홀더를 제거한 마지막 결과**를 사용한다.

## 기준 파일

2026-09-27 후속 선택: 팔라딘·다크나이트·나이트로드·섀도어·팬텀은 비숍 공통 그림체·비율 수정본을 각 폴더의 `concept.png`에 저장했다. 팬텀은 사용자가 지정한 아래쪽 마지막 수정본(카드 3장)을 사용한다. [5직업 제작 기록](five-class-concepts.md) 참고. 이전 원화는 `.beaver/output/five-class-design/previous-concepts/`에 보관했다.

## 후속 작업 범위

- 보우마스터는 비숍 기준 수정 원화와 한쪽 무릎 애로우 레인 자세를 사용자에게 승인받았다. 대기·폭풍의 시·애로우 레인·흉상 업로드와 게임 연결, Maker 검증 및 사용자 최종 승인을 완료했다. [보우마스터 모션](bowmaster-motion.md) 참고.

- 최초 작업은 원화 저장과 인계였으며 아래 항목에 후속 진행 상태를 갱신한다.
- 신궁은 비숍 엔젤레이를 기준으로 인체비율·표정·그림체를 맞춘 대기·공격 프레임을 새 RUID로 연결했다. Maker 실제 재생 후 사용자가 현재 모션을 승인했다. 세부 상태는 [신궁 모션](marksman-motion.md)을 따른다. 보우마스터도 적용을 완료했다. 나머지 5종은 원화와 대기·공격 PNG 78장까지 저장했고 게임 적용 전이다. [5직업 모션 기록](five-class-motion.md)을 따른다.
- 그림체·비율·원화/프레임/흉상 구성은 현재 비숍을 공통 기준으로 한다. [유닛 원화 규칙](../unit-art.md)과 [비숍 기준 생성 프롬프트](unit-art-prompts.md)를 사용하며 실제 비숍 이미지를 생성 참조로 첨부한다. 각 직업의 승인된 외모·색·의상·무기·표정 컨셉은 유지한다. 원화의 캔버스 크기를 전투 프레임 규격으로 취급하지 않는다.
- 다크나이트의 비홀더가 있는 초기 생성본이나 사용자 첨부 참고 이미지를 최종 기준으로 선택하지 않는다. 팬텀은 한 종류만 사용한다.
- 생성 프롬프트와 과거 출력 기록은 [.beaver/output/character-concepts/prompts.md](../../.beaver/output/character-concepts/prompts.md)에 있다. 후속 작업의 기준 파일은 위 자산 경로다.
