# 보우마스터 모션

사용자 최종 승인 완료: 보우마스터의 현재 원화·대기·폭풍의 시·애로우 레인·흉상을 확정했다. 애로우 레인 황금 활은 개인 활 사출구 정렬(loopDx=0, loopDy=0.68, 좌우 ±12도), 캐릭터 뒤 표시(loopOrder=-2)를 최종값으로 유지한다.

승인된 원화와 비숍 공통 작화·인체비율 기준으로 제작하고 게임에 연결했다. 와인색 땋은 긴 머리, 녹색 눈, 흰 깃털, 녹색·갈색 의상, 금색·아이보리 활, 작은 닫힌 입 미소를 유지한다.

## 결과물

대기 576×576·발 (288,512), 공격 704×704·발 (352,640), 픽셀당 로컬 0.002유닛. 대기는 활을 내리고 작은 호흡을 반복한다. 폭풍의 시는 수평 조준·시위 당기기·발사·반동·재장전이다.

애로우 레인은 사용자 승인 키 포즈를 따른다. 캐릭터 왼발을 뒤로 빼고 그쪽 무릎을 땅에 짚으며 오른발을 앞에 둔다. 허리와 어깨를 비스듬히 틀고 활을 머리 위에서 약간 기울여 든다. 화살은 수직 위로 발사한다. 05는 02의 시위 당기는 자세를 다시 사용해 반복을 연결한다. 프레임 파일 13장, 고유 프레임 RUID 12개, 흉상 RUID 1개다.

## 게임 연결

`RtsJobTableLogic.mlua`의 HasMageSkin, GetMageSkinFrames, GetMageSkinFrameDurations, GetMagePortraitRUID에 bow 분기를 추가했다(2026-09-28 지금은 `JobDefs.bow` 항목 하나). 폭풍의 시는 bowHurricane, 프리즘 애로우 레인은 bowArrowRain으로 연결한다. 기본 아바타는 생성하지 않는다.

기존 PlayMageLoop를 사용하여 0.2초마다 공격 요청이 들어와도 프레임 시계를 리셋하지 않는다. 공격 요청이 0.6초 이상 끊기면 기존 CheckLoops 감시 주기에 따라 stand1으로 복귀한다. 피해·사거리·공격 주기·쿨타임·스킬 이펙트는 이번 작업에서 변경하지 않았다.

RUID·소스 크롭·파일 해시는 [.beaver/output/bowmaster-motion/manifest.json](../../.beaver/output/bowmaster-motion/manifest.json), 공개 업로드 목록은 [uploaded.json](../../.beaver/output/bowmaster-motion/uploaded.json), 생성 지시는 [prompts.md](../../.beaver/output/bowmaster-motion/prompts.md)에 있다.

## 검증

- Maker 새로고침·저장·Play 적용 후 빌드 오류 0 (기존 경고·정보 157건).
- 실제 자동 공격에서 폭풍의 시 5/5 고유 프레임, 애로우 레인 4/4 고유 프레임을 양방향 모두 확인했다. 5번 재장전 파일은 2번과 동일하다.
- 실제 대상 체력이 감소했으며, 공격 잠금 후 양쪽 유닛이 stand1의 3개 고유 프레임으로 돌아왔다.
- 캐릭터 상세정보와 영입 상세정보의 흉상을 화면으로 확인했다.
- 검증용 서버 스크립트의 client 조회 호출 오류 1건은 서버 GetUnit 조회로 수정했다. 게임 코드 오류는 아니며 수정 후 검증에서 실행 오류 0.
- 확인 중 숨긴 루프 이펙트와 임시 공격 잠금은 복구 완료했다. 시험용 보우마스터 2기는 현재 Play 세션에만 배치하며 영구 저장하지 않는다.

위쪽 유닛은 폭풍의 시, 아래쪽은 프리즘 애로우 레인이다.


애로우 레인 황금 활·날개 이펙트는 캐릭터 모션을 가리지 않도록 loopDy를 최종 0.68(개인 활 사출구 기준)로 맞췄다. 등장 효과는 루프의 자식이며 loopIntroDy=0이므로 동일 높이에 이어진다. 크기·투명도·프레임·타격 위치는 유지한다.

애로우 레인 이펙트 회전: 캐릭터가 든 활의 양끝을 잇는 기울기에 맞춰 loopRotation=12도. 왼쪽 보기 +12도·오른쪽 보기 -12도이며 소환 효과도 부모 회전을 그대로 따른다. 실제 낙하 투사체는 기존 수직 궤적을 유지한다.

황금 활 사출구 정렬: loopDx=0, loopDy=0.68, loopRotation=12. 개인 활의 화살 통과점 약 (307,222)px와 황금 활 원본 pivot 상대 (2,92)px를 비교하고 크기·회전을 반영했다. 좌우 회전 ±12도 유지. 황금 날개가 캐릭터를 가리지 않도록 loopOrder=-2, 소환은 -1, 캐릭터는 0으로 표시한다. 높이만 올린 이전 2.5/2.1/1.9/1.5 시안은 대체한다.
