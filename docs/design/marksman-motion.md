# 신궁 모션 디자인

**최종 상태: 게임 적용·Maker 재생·사용자 승인 완료.** 비숍 frames/angel-ray의 인체비율·표정·그림체를 기준으로 짧은 다리·부츠와 차분한 눈매·작은 닫힌 입 미소를 적용했다. 대기 3장·피어싱 6장·스나이핑/트루 스나이핑 각 5장을 교체하고 고유 프레임 14개를 새 RUID로 연결했다. Maker 실제 재생과 사용자 확인을 완료했으며 현재 모션으로 확정했다. 피해·판정·쿨타임은 유지한다.

사용자가 실제 플레이를 확인하고 “모션괜찮은데? 이대로 해도될듯”으로 승인했다. 산호색 머리·청록 눈·녹색 의상·석궁의 정체성을 유지한다.

## 외형 기준

`assets/design/characters/marksman/concept.png`는 산호색 포니테일, 청록 눈, 깃털 모자, 녹색·금색 의상, 검은 망토, 흰 부츠, 흰색·녹색·금색 석궁의 정체성 참고다. **그림체·인체비율·표정의 우선 기준은 비숍 `frames/angel-ray/motion01.png`~`motion05.png`다.** 대기는 다리 간격을 좁히고 허리를 편 편안한 선 자세, 아래로 내린 석궁. 큰 열린 입 미소와 긴 허벅지·부츠를 이어받지 않는다. 조준 중에도 기준 얼굴의 크기·눈매를 유지한다.

## 동작·시간

- 피어싱: **선 자세에서 무릎만 살짝 굽혀 조준 후 사격**. 무릎을 땅에 대지 않는다. 01→06, 0.08/0.09/0.18/0.09/0.10/0.16초. 사격 자세는 현재 첫 타격 0.35초에 맞춘다.
- 스나이핑: **즉시 무릎을 낮춰 저격 모드 → 연사 → 원래 자세**. 서서 천천히 앉는 준비 프레임은 제외했다. 01(낮은 자세)0.10초→02(조준)0.30초→03(반동)/02를 각0.04초씩 10회→04(일어서기)0.10초→05(대기 복귀)0.10초. 연사 시작 0.40초, 기존 0.08초 타격 간격을 참고했다.
- 트루 스나이핑: 01 0.08초→02 0.28초→03/02 각0.025초씩 10회→04 0.08초→05 0.10초. 기존 첫 타격0.36초·간격0.05초를 참고했다.
- 대기: 편안한 선 자세에서 작은 호흡·머리카락·망토 변화. 01→02→01→03, 0.65/0.45/0.65/0.45초. 전체 이미지 위치 흔들기·크로스페이드 없이 프레임을 교체한다.

위 시간표를 `RtsJobTableLogic.GetMageSkinFrameDurations`에 연결했다. 조준 표식·투사체·피격 이펙트·소리와 피해·판정·쿨타임은 기존 값을 유지한다. `HasMageSkin("marks")`가 전용 외형을 활성화하고, `marksPiercing`·`marksSniping`·`marksTrueSniping` 액션을 각각 연결한다. `GetMagePortraitRUID("marks")`는 영입창·상세정보 공용 흉상을 반환한다. 공격 프레임의 대기 복귀는 공용 `RtsSkillFxLogic`의 시간표 합계를 따른다.

## 적용 검증

- 최종 결과는 `assets/design/characters/marksman/frames/{wait,piercing,sniping,true-sniping}/motionNN.png`의 총 19장이다. 스나이핑·트루 스나이핑은 동일한 5개 PNG와 RUID를 공유하고 시간표만 구분한다.
- 고유 프레임 14개를 새 RUID로 업로드하고 `RtsJobTableLogic`에 연결했다. 기존 `portrait.png`와 흉상 RUID는 유지한다.
- PNG 크기·투명도·해시·코드의 프레임 순서·시간표를 대조했다. 피어싱 시트의 경계 영역을 조정해 화살·머리카락을 보존하고 저격 자세는 망토가 아닌 발바닥 기준으로 배치했다.
- Maker `refresh_workspace → save → build 로그 → play` 실행. 빌드 오류 0개(경고 10개), 재생 로그 오류 0개. 실제 전투 루프에서 `stand1`, `marksPiercing`, `marksSniping`, `marksTrueSniping`과 공격 후 대기 복귀를 확인했다. 135개 프레임 전환 표본 모두 외형 준비 상태가 true였다.
- 시험용 신궁 3기: 위 피어싱 / 가운데 스나이핑 / 아래 트루 스나이핑. 현재 Play 세션의 임시 배치이며 사용자가 재생을 확인하고 현재 모션을 승인했다. 확인 중인 화면은 그대로 유지했다.
