## 연결 동작과 시간

| 프레임 | 동작 | 유지 시간 |
|---|---|---:|
| 01 | 카드를 모으며 무릎을 낮추는 준비 | 0.06초 |
| 02 | 카드 손을 얼굴 옆으로 높이 당김 | 0.05초 |
| 03 | 팔을 몸 앞을 가로질러 빠르게 뻗음 | 0.04초 |
| 04 | 낮은 방향 손목 스냅·카드 놓기 | 0.06초 |
| 05 | 팔·어깨의 후속 동작과 반동 | 0.04초 |
| 06 | 다음 카드를 당기는 회수 | 0.05초 |
| 07 | 두 번째 전방 손목 스냅·카드 놓기 | 0.05초 |
| 08 | 팔을 접으며 다음 연사로 연결 | 0.05초 |

1~8번은 총 0.40초 반복한다. 소스의 투척 방향은 왼쪽이며 얼굴과 코트 앞면을 계속 보여 준다. 프레임 전체를 회전·확대하거나 크로스페이드해서 몸동작을 대신하지 않았다. 각 자세를 ImageGen으로 그렸다. 보라색 눈 범위를 비교 보조값으로 삼아 표시 배율을 맞추고 발 위치를 정렬했으며 전체 시트로 재검수했다.

별도 카드 레이어는 미리보기에서 0.10초마다 발사되고 약 1.05초 동안 곡선 이동·카드 자체 회전을 한다. 최신 사용자 요청으로 승인된 카드·고리 외형 비율을 유지하며 카드 표시 크기를 144×216에서 288×432로 다시 2배 확대했다. 원본 카드 PNG와 캐릭터 모션·비행 속도·간격은 그대로다. 카드 확대 뒤 기존 고리가 가려지는 문제를 수정하여, 고리도 카드에 맞춰 316×316에서 632×632로 다시 2배 확대했다. 각 카드에는 이 크기의 흰색·분홍색 원형 소용돌이 PNG를 함께 표시하고 독립적으로 회전시킨다. 기존 절차형 얇은 호는 이 이미지로 교체했다. 이는 원본 영상의 카드 연사 느낌을 확인하기 위한 로컬 재생이며 게임 판정·비행 시간·이펙트 변경 완료를 뜻하지 않는다. 몸이 돌아가는 동작과 날아가는 카드의 회전을 구분한다.

## 검수·적용 상태

프레임 8장의 크기·투명도·가장자리 잘림 검사 통과. 기존 대기 및 다른 4직업 프레임 70개와 승인 원화 5개의 해시가 그대로임을 확인했다. 5직업 전체 캐릭터 PNG는 78장(대기 15 + 스킬 63)이며 별도 카드 PNG와 원형 소용돌이 PNG, 총 2장의 효과 자산을 둔다. 프레임 04/07의 떠 있는 카드와 05의 잘못 추가된 허리 카드는 다시 생성해 제거했다.

후속 다리 간격·반동 수정은 기존 각 프레임을 편집 대상으로 built-in ImageGen에 전달했다. 프롬프트는 발 간격을 약 18% 줄이고 무릎·상체 반동만 보강하도록 지정하며, 캐릭터 정체성·비율·손 궤적·케인 목 그립·몸 회전 금지를 유지한다. 생성된 원본과 9개 완성 프롬프트(몸 8 + 고리 1)는 `.beaver/output/phantom-joker-refine/`의 `motion01.json`~`motion08.json`, `ring.json`에 있다. 기존 카드 그림은 고해상도 원본으로 다시 저장했다.

이전 작업 원본·참조 경로와 현재 재생·검사 결과는 `.beaver/output/phantom-joker-video/`에 있다. 반려된 작은 제스처는 같은 폴더 `rejected-small-gesture/`에 보관했다. 이전 회전 컷과 작은 제스처는 현재 적용 파일이 아니다.
