## 그림체·정렬

현재 비숍의 실제 대기·엔젤레이 프레임을 생성 참조로 사용했다. 승인된 5종 원화의 외모·의상·무기를 유지하고 비숍의 짧은 몸통·팔다리와 작화 방식을 따른다. 대기 576×576, 기본 공격 704×704 투명 PNG이며 발 기준은 각각 (288,512), (352,640). 기준 머리 길이는 147px이고 중립 신체는 약 2.3등신이다. 모자·깃털·무기 길이를 신체 높이에 포함하지 않는다. 포즈별 원근과 무릎 굽힘 때문에 전체 외곽 높이는 같지 않다.

다크나이트 스피어 버스터의 후속 승인본은 832×832·발 (416,768) 예외를 사용한다. 상단 → 하단 → 정면으로 깊게 찌르며 거대화는 두 번 반복한다. 현재 파일·RUID는 [적용 기록](paladin-dark-knight-motion.md)을 따른다.

정규화는 균등 배율과 캔버스 위치만 조정했다. 머리 실루엣 자동 측정을 시각 검수하고 해머가 머리로 잘못 잡힌 팔라딘 일부 컷은 수동 보정했다. 다크나이트 비홀더는 없다. 초기 제작 당시 스피어 버스터 6번의 창 방향, 팬텀 준비 컷의 케인·카드 손 위치, 나이트로드 대기의 불필요한 입김을 다시 생성해 수정했다.

## 스킬 연결 인계

| 시퀀스 | 재생 시간 / 연결 메모 |
|---|---|
| 대기 | 1→2→1→3, 0.65/0.45/0.65/0.45초 반복 |
| 디바인 차지 | 6장 0.75초. 올려치기 타격 0.30초 |
| 생츄어리 | 6장 0.90초. 내려찍기 타격 0.50초 |
| 스피어 버스터 | 상단 → 하단 → 정면, 8파일(고유 6장) 0.70초 + 기존 준비 0.50초. 타격 0.65/0.80/0.95초. 거대화는 세 방향을 두 번 반복하는 14단계·1.20초로 반복 연결 완료 |
| 드래곤 로어 | 6장 1.40초. 시전 0.60초 |
| 쿼드러플 스로우 | 8장으로 4회 투척, 반복 포함 0.70초. 발사 0.10/0.20/0.30/0.40초 + 기존 비행 0.20초. 풍마수리검은 몸동작 공유, 투사체는 별도 |
| 새비지 블로우 | 8장 반복 포함 0.50초. 타격 0.10초부터 0.05초 간격 8회 |
| 메소 익스플로젼 | 5장 0.50초. 손동작 시전 0.30초 |
| 블레이드 토네이도·카르마 퓨리 | 8장 3.20초. 방출 0.30초, 기존 타격 0.60~3.10초. 유지 자세 6번을 2.10초 유지 |
| 조커 | [영상 기준 8장](phantom-joker-motion.md), 1~8번 총 0.40초 연사 반복. 몸 회전 없음. 케인 목을 쥐어 들고 왼쪽으로 투척. 카드·원형 소용돌이 PNG 별도, 카드 표시 288×432(직전의 2배), 고리는 632×632으로 함께 확대. |

팬텀은 사용자의 명시 정정에 따라 몸 회전 해석을 폐기하고 같은 방향으로 카드를 연속 투척한다. 선택된 마지막 콘셉트의 큰 모자, 흰색·청색·금색 코트, 붉은 보석 케인과 와인색·금색 카드 뒷면을 유지했다. 비행 카드와 회전 궤적·공격 이펙트는 몸 프레임에 굽지 않았다. 현재 게임의 카드 투사체 외형·궤적 변경과 새 프레임 연결은 별도 적용 작업으로 남아 있다.

## 검수

수정된 21개 파일의 크기·알파·캔버스 가장자리 검사를 통과했고 전체 파일 수는 78개다. 승인 원화 5개의 SHA256은 작업 전과 동일하다. 5직업 전체 프레임 시트에서 얼굴·무기·손·앞뒤 방향과 발 정렬을 확인했다. 로컬 재생 순서와 타이밍을 저장했다. 팔라딘·다크나이트는 Maker 32/32 로딩, 좌우 모든 공격 프레임과 대기 복귀를 확인했다. 나이트로드·섀도어의 후속 검증은 [적용 기록](night-lord-shadower-motion.md), 팬텀은 Maker 검증 전이다.
