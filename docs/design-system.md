# 메이플 증강 디펜스 — 디자인 기준과 구현 인계

화면의 실제 동작·좌표·갱신 규칙은 [ui-screens.md](ui-screens.md), 테마는 [theme-presets.md](theme-presets.md), 캐릭터는 [unit-art.md](unit-art.md)를 따른다.

## 디자인 방향

사용자가 승인한 현재 방향은 **새하얀 반투명 패널과 은은한 흰 물결**이다. 기존 크림·브라운 및 청록 물결 방향을 대체한다. 승인 시안은 `assets/design/ui/concept-white-wave.png`이며, 실제 문구·수치는 게임 데이터를 사용한다. 시안 이미지를 통째로 화면에 붙이지 않는다.

- 백색 바탕·얇은 은색 테두리·연보라 선택 표시·짙은 회색 글자. 프로필 설정/연결 화면과 좌상단 프로필·정보 상자는 불투명하게 표시한다.
- 물결은 낮은 대비의 정적인 장식이다. 본문 뒤에서 반복적으로 반짝이거나 움직이지 않는다.
- 썬콜은 승인된 흉상을 사용한다. 다른 직업은 새 흉상이 준비될 때까지 기존 아바타를 표시한다.
- 브론즈·실버·골드·프리즘은 색뿐 아니라 서로 다른 문양으로 구분한다. 문양 가운데 능력치 그림을 넣는다.
- **직업 프리즘 11종은 대응하는 공식 스킬 그림을 가운데 넣는다.** 공통 프리즘 2종은 효과에 맞는 능력치 그림을 사용한다.
- 보유·도감·뽑기·캐릭터 상세의 증강 아이콘은 같은 생성기를 쓴다. 등급과 아이콘을 별도 글자로 이어 붙이지 않는다.

## 구현과 자산

UI는 클라이언트 런타임 엔티티로 생성한다. `SpawnPanel/SpawnRoundedPanel`은 안쪽 패널을 반환하는 기존 계약을 유지한다.

| 자산·도우미 | 용도 |
|---|---|
| rounded-panel.png / rounded-outline.png | 채움과 비어 있는 테두리를 분리. 64×64, 12px 9-slice |
| water-flow.png | 백색 물결 1024×512, `SpawnWater` 공용 장식 |
| stat-*.png | 공격력·공격력%·최종·보스·크리 확률·크리 데미지 및 공통 스킬 그림 |
| grade-*.png | 등급별 문양4종, 중앙에 그림을 넣는 공용 바탕 |
| resources.json | 업로드 RUID 및 프리즘 스킬 RUID 매핑 |
| tools/gen-ui-assets.cjs | 위 공용 UI 자산의 재생성 원본 |
| RtsPopupLogic.SpawnAugIcon | 등급 바탕 + 능력치/스킬 그림을 고정 크기 컨테이너에 합성 |

보유 목록·캐릭터 상세는64px, 도감68px, 선택 상세72px, 3택1은104px 문양을 사용한다. 신규 비트맵은 프로젝트에 저장하고 업로드 후 연결한다. 기존 RUID 바이너리 교체는 Maker 캐시로 이전 그림이 남을 수 있으므로 시각 변경에는 새 RUID를 연결한다.

## 부분 갱신

숨기기 체크는 `ApplyAugFilter`가 기존 행의 표시 여부와 체크 표시만 갱신한다. 등급별 보유 탭은 없다. 선택된 항목이 숨겨질 때만 상세 선택을 바꾼다.

탭·동기화로 내용 교체가 필요하면 `SwapContent`가 새 컨테이너를 alpha0·입력 차단으로 준비하고 이전 컨테이너 제거와 함께 표시한다. 반투명 면이 동시에 쌓여 밝아지는 현상을 막는다. 바깥 셸·흉상·능력치는 유지한다. 같은 탭의 스크롤은 복원한다.

## 적용 범위

캐릭터 상세·영입·보유 증강·뽑기·도감·프로필·아이콘·결과·확인창·난이도 선택·HUD/플레이어 카드에 공용 스타일을 적용했다. 캐릭터 상세는 흉상/공식 직업명·레벨, 6축 능력치, 액티브/패시브/증강/버프의 구획으로 표시한다. 레벨업 문구는 ‘레벨업’, 최대 상태는 ‘최대 레벨 도달’이다.

유저 카드는400×96의 낮은 가로형이다. 각 사용자가 선택한 테마 썸네일을 원본 비율로 확대해 가운데를 잘라 배경으로 표시한다. 왼쪽68px 아이콘 영역, 오른쪽 정렬한 흰 닉네임과 그림자를 사용한다. 내 카드에는 초록 테두리와 상단 중앙 마름모 문양을 더한다.

프로필 아이콘 목록은6열이며 카드128×140 안에서 상태·썸네일76×76·이름을 위에서 아래로 분리한다. 명시적인 행 컨테이너818×150으로 배치해 엔진 기본 격자 크기에 의한 겹침을 막는다. 테마·비석·아이콘 변경 확인은 기존 프로필 위의 별도 레이어로 띄우며, 닫으면 기존 목록과 스크롤을 그대로 유지한다.

난이도 선택은 시작 전(idle·countdown)에만 상단 중앙에 표시한다. 바로 시작은 선택창 아래, 진행·종료 중 다시하기는 선택창이 사라진 상단 중앙 자리에 표시한다. 좌상단의 난이도 텍스트는 제거한다.

증강 선택 카드의 등급·이름·효과는 가로 중앙 정렬이다. 보유 증강 이름과 미지정 표시는 행의 세로 중앙에 맞춘다. 대상 선택은 왼쪽 직업명·오른쪽 레벨을 한 줄에 표시하며 유닛 번호는 생략한다.

몬스터·보스 상태창과 디버프 설명에도 같은 백색 물결 디자인을 적용한다. 모바일 별도 설계·멀티플레이 검증은 이번 결과에 포함하지 않는다. Phase 11은 사용자 최종 시각 확인 전까지 진행 중이다. 실제 검증 범위는 `.beaver/output/report/rts-ui/ui-renewal-report.md`에 기록한다.

## 보유 증강·미선택 증강·유닛 목록

- 보유 탭 왼쪽 목록에 미선택 증강을 한 건씩 표시한다. 각 행은 등급 문양·공통 선택 아이콘·등급명·미선택 표시로 구성하며, 적용된 증강 숨기기와 관계없이 보인다. 원하는 행을 누르면 해당 건의 3택1을 열고, 받으면 보유 목록의 미지정 증강이 되어 유닛에 지정할 수 있다. 받은 증강과 미선택 건수는 구분한다.
- 증강 뽑기 탭은 구매 전용이다. 미선택 증강이 있어도 선택 화면으로 바뀌지 않고 구매 후에도 뽑기 페이지를 유지한다. 선택 화면은 보유 탭에 속한다. 증강 입구는 항상 보유 탭을 연다.
- 우측 유닛 목록은 방출 후 내부 유닛 번호 순으로 위쪽부터 빈칸 없이 표시한다. 직업명 앞 번호는 모두 제거한다. 행 클릭·선택은 원래 유닛 번호를 보존한다.
- 몬스터·보스 상태창은 백색 물결의 640×208 둥근 패널이다. 왼쪽 96px 초상, 오른쪽 이름·종류 배지·체력 수치·10px 체력바·라운드/맵과 보스 방어율, 아래 디버프 칩을 분리한다. 디버프 설명도 같은 밝은 디자인이다.
