# balance

전투·성장·메소 밸런스 규칙. 수치 원본은 `.info/character.md`(스킬), `.info/level.md`(비용), `.info/damage.md`(계산식·표 규칙), `.info/balance-detail.md`(비교표·특성표·직업별 표) — 여기엔 계산 규칙 요약과 설계 의도만.

## 공격 사이클 = 모션·이펙트·사운드 동시 시작, 공격속도에 맞춰 배속
- Rule: 공격 1회 = t=0에 아바타 모션 + 스킬 이펙트 + 사운드 동시 시작. 이펙트는 1회 재생 후 제거, 모션은 끝나면 stand 복귀. **배속 = max(1, 이펙트 길이 ÷ 공격 주기)** — 모션·이펙트에 같은 PlayRate, 사운드는 배속 없이 그대로 재생하며 이전 사운드를 끊지 않고 겹침 허용(StopSound 안 씀). 공격속도: 매우느림 1.5초 / 느림 1.25 / 보통 1.0 / 빠름 0.75 / 매우빠름 0.5초당 1회.

## 사거리·타겟 규칙: 걸치면 사거리, 가까운 순 n마리, 없으면 안 침, 들어오면 즉시
- Rule: 스킬 설명 틀 = "사거리 n. x% 데미지로 n마리를 m회 타격"(2026-09-15 "타일 범위" → "사거리"로 표기 변경 — 타일이 기준이지만 사실상 사거리). 사거리 = 패드 기준 주변 n칸(대각선 포함)의 트랙 칸. 몬스터가 범위 타일에 **살짝이라도 걸치면** 사거리 안. 타겟 = 범위 안 몬스터 중 **캐릭터와 가까운 순**으로 n마리(단일/다수 공통, 동거리면 트랙 진행이 앞선 쪽). **타겟 수(n마리)와 타격 수(m회)는 별개** — 타겟마다 m회 각각 데미지 비율 적용. 범위 안에 몬스터가 하나도 없으면 공격 사이클 자체를 시작하지 않고(모션·이펙트·사운드 없음), 들어오는 순간 **즉시 실행**(선딜 없음) 후 그 시점부터 공격 주기 카운트. 주기 타이머는 대상 없을 때 돌리지 않음.
- Scope: project
- Rationale: User decisions 2026-09-15 — "타일에 살짝 걸치기만해도 사거리", "공격은 그 조건에 해당하는 몬스터가 1마리라도 있어야", "들어오는 순간 스킬 실행임", "타겟수와 타격수를 나눔"

## 데미지 계산식 = 7단계 (합/곱 그룹이 핵심, 곱 순서는 무관)
- Rule: ① **공격력** = 기본(1레벨) + 성장(레벨업당 × (레벨−1)) + 스킬·증강·버프 +수치 합 → ② **공격력%** 합연산(10%+10% = 20%, "200%로 변경" = +100%) → ③ **보스 공격시 데미지 증가** 합연산(보스만; 증강·발할라 증강·블스아이) → ④ **크리티컬 데미지** 합연산(기본 20%, **상한 없음**; 확률은 기본 0%·상한 100%; 크리 시 ×(1+크뎀), 표·팝업은 기대값) → ⑤ **스킬 데미지** 비율(1회 타격 기준) 합연산(레이징 블로우 200% + 증강 20% = 220% → ×2.2) → ⑥ **최종 데미지** 끼리 곱연산(30%·30% = ×1.69; 홀리 유니티·프레이·조커·디바인 블레싱·인피니티·상태이상) → ⑦ **방어**: 남은 방어율 = 몬스터 방어율 − 방무(0 미만 0) → ×(1 − 남은 방어율). 코드 `RtsJobTableLogic.CalcStat`(bossAdd = ③, fin/finBoss = ⑥), 표 생성기 `balance_gen.py`, 목업 `calc()` 모두 이 그룹 규칙. 원문 `.info/damage.md`.
- Scope: project
- Rationale: User decisions 2026-09-15("방어가 맨 마지막", "공격력 배율은 합연산", "최종데미지는 곱연산", "크리 기본 20%") → 2026-09-16 7단계로 재정리("계산식 다시 정리할게 … 이렇게 되있나 확인해봐") — 기존 구현과 그룹이 같아 순서 표기만 맞춤
