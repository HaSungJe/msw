# 패치노트 작성 양식

- 사용자 확정: 2026-09-27, "패치노트 양식을 앞으로 이렇게 고정하자. 프로젝트에 메모해놔".
- 적용 범위: 이 프로젝트의 이용자 공지용 패치노트. 별도 요청이 없으면 아래 양식을 사용한다.
- 제목은 굵은 글씨로 `M월 D일 업데이트 안내`라고 쓴다.
- 변경 사항은 주제별로 묶어 최상위 불릿에 굵은 제목을 쓰고, 세부 내용은 한 단계 들여쓴 불릿으로 적는다.
- 각 문장은 한국어 존댓말로 짧고 구체적으로 쓴다. 이용자가 체감하는 추가·변경·개선 결과와 필요한 사용 위치를 설명한다.
- 이번 업데이트에 해당하는 주제만 넣는다. 예시의 주제나 개수를 매번 억지로 맞추지 않는다.
- 코드명·파일 경로·RUID·검증 로그 등 내부 구현 정보는 공지 본문에 넣지 않는다. 게임 내 직업명·스킬명·버튼명은 정확히 쓴다.
- 중요한 동작 순서나 수치만 필요할 때 굵게 강조한다. 인사말·맺음말·이모지·표는 기본 양식에 추가하지 않는다.
- 버전을 표기해야 하면 workflow.md의 실제 게임 버전 규칙을 따른다. 패치노트 작성만으로 버전이나 커밋 순번을 새로 만들지 않는다.
- 실제 변경 내용을 확인해 작성한다. 아래 예시는 양식 기준이며 이후 업데이트에 그대로 재사용할 변경 목록이 아니다.

## 기본 템플릿

```markdown

- **기능명 추가**

  - 추가된 동작이나 편의 기능을 설명합니다.

- **개선 대상 개선**
  - 이용자가 확인할 수 있는 변경 결과를 설명합니다.
```

## 사용자가 승인한 예시

**9월 27일 업데이트 안내**

- **다크·라이트 모드 추가**
  - 화면 오른쪽 아래에서 원하는 모드를 선택할 수 있습니다.
  - 선택한 모드는 저장되어 다음 접속에도 적용됩니다.
  - 일시정지 버튼을 화면 상단으로 옮겼습니다.

- **캐릭터 외형 개선**
  - 11개 직업의 그림체와 신체 비율을 통일했습니다.
  - 직업별 대기·공격 모션을 개선하고, 영입·상세 화면에 전용 흉상을 적용했습니다.

- **스킬 모션 개선**
  - 다크나이트의 스피어 버스터를 **상단 → 하단 → 정면**의 3단 찌르기로 변경했습니다.
  - 팔라딘·나이트로드·섀도어의 스킬별 전용 모션을 적용했습니다.
  - 팬텀의 조커를 연속 카드 투척 모션으로 변경했습니다. 카드와 원형 효과를 확대하고, 캐릭터 앞에서 자연스럽게 발사되도록 위치를 조정했습니다.

- **영입 화면 개선**
  - ‘잠김’ 문구를 캐릭터 중앙의 반투명 자물쇠 아이콘으로 변경했습니다.
