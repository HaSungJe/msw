# Roadmap — 메이플 운빨 디펜스 (8인 개인전 · 랜덤 뽑기+조합 · 구역 웨이브 디펜스)

> 2026-08-02 컨셉 피벗으로 wall-survival-roadmap.md를 대체. 피벗 근거·자산 처분표: [pivot-luck-defense.md](pivot-luck-defense.md)

## Direction
스타1 유즈맵 '메이플 운빨 디펜스'를 MSW 탑다운으로 재현한다. 최대 8인이 **각자 자기 구역(한 화면 크기)**에서 골드로 **랜덤 유닛을 뽑고**(운빨) 같은 유닛을 **조합해 상위 등급**을 만들며, 구역을 순환하는 몹 웨이브를 처리한다. **처리 못 한 몹이 일정 수 쌓이면 비석과 함께 개인 탈락**. 카메라는 자유 이동 없이 **F1~F8로 구역 시점 전환만**. (방향은 느슨하게 유지)

## Scope & Actors
- **플레이어(1~8)** — 자기 구역에서 뽑기/조합/유닛 운용. F1~F8로 다른 유저 구역 구경 가능.
- **방장** — 방 생성·난이도 선택·시작.
- **시스템(서버)** — 웨이브 스폰·순환, 누적 카운트·탈락 판정, 뽑기 확률, 라운드/보스, 승패.
- **커스터마이즈 축** — 난이도(몹 스탯 %), 방 인원(1~8).

## Non-Goals / External Boundaries
- 자유 카메라(엣지/방향키 스크롤, 마우스 가두기) **금지** — F1~F8 시점 전환만 (사용자 확정).
- 벽 건설·수리·길찾기 없음 (벽짓살 잔재 — 몹은 고정 순환 경로).
- PvP 직접 전투 없음 (간접 경쟁: 생존/기록).
- 전장의 안개 없음. 모바일 최적화 1차 제외(PC 중심).

## Cross-Cutting Rules
- **모든 판정은 서버** — 골드, 뽑기 결과, 몹 스폰/누적, 탈락, 승패는 `@ExecSpace("Server")`. 클라는 입력·표시만.
- **밸런스 수치는 테이블 일원화** — 뽑기 확률·비용, 웨이브/보상, 몹 스탯을 데이터 테이블 Logic에. 난이도 %는 그 위에 곱한다.
- **구역 좌표는 구역 시스템(#4) 경유** — 구역 인덱스↔월드 좌표 변환은 단일 소스.
- **HUD 갱신은 RtsHudLogic API 경유** — 스킬칸(SetSkillSlot), 부대탭, 골드/시간 표시는 직접 UI 조작 금지.
- **키보드는 PC 전용**, 바닥은 반드시 RectTileMap(#1 확립 — SpriteRenderer 타일드 금지).
