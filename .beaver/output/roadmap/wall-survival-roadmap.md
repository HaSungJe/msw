# Roadmap — 벽짓살 MSW판 (탑다운 풀 RTS 디펜스: 벽으로 막고, 경제 키우고, 제한시간 내 보스 처치)

## Direction
스타크래프트2 유즈맵 '벽 짓고 살아남기'를 MSW 탑다운 풀 RTS로 재현한다. 플레이어는 일꾼으로 벽·수익건물·포탑·병영·업그레이드센터를 지어 상시 스폰되는 몹을 막고 경제를 키운 뒤, 제한시간 내에 맵 중앙의 보스 건물을 부수고 각성한 보스를 처치하면 승리한다. 방 생성→입장→시작 구조로 멀티/솔로 모두 지원하며, 일꾼이 죽은 유저는 개인 탈락(비석)한다. (방향은 느슨하게 유지 — 개발 중 변경 가능)

## Scope & Actors
- **플레이어** — 일꾼·전투유닛을 RTS 조작(클릭/드래그 선택, 부대지정 Ctrl+숫자, 단축키, 카메라 스크롤)으로 지휘. 건설/업그레이드/전투 판단 주체.
- **방장** — 방 생성, 난이도 선택, 게임 시작.
- **시스템(서버)** — 몹 스폰·AI·강화 스케일링, 보스 각성·추격, 경제 틱, 승패 판정.
- **커스터마이즈 축** — 난이도(몹 공격력/공속/체력/방어력 %스케일), 방 인원(솔로~멀티).

## Non-Goals / External Boundaries
- **PvP 없음** — 순수 PvE 협동/개인 생존.
- **전장의 안개(시야) 1차 미도입** — MSW 네이티브 미지원, 필요 시 이후 신규 유닛으로.
- **모바일 최적화 1차 제외** — 풀 RTS 조작(키보드+마우스)은 PC 중심. 모바일 대응 범위는 Open Decision.
- **운빨 디펜스 컨셉 폐기** — 랜덤 뽑기/조합 요소 없음.
- 메이플 IP 리소스 사용은 MSW 정책 범위 내에서만.

## Cross-Cutting Rules
- **모든 판정은 서버** — 자원 차감, 데미지, 사망, 승패, 몹 스폰은 `@ExecSpace("Server")`. 클라이언트는 입력·표시만 (WorldConfig AuthorityCheck 활성 상태).
- **좌표는 논리 그리드 경유** — 배치·점유·길찾기는 전부 #2 GridLogic 좌표계를 단일 소스로 사용. 월드 좌표 직접 계산 금지.
- **밸런스 수치는 테이블로 일원화** — 비용·수입·HP·데미지·스폰 곡선을 코드에 하드코딩하지 않고 한 곳(데이터 테이블 Logic)에 모은다. 난이도 %스케일(#15)이 이 테이블 위에 곱해진다.
- **키보드 입력은 PC 전용** — 모든 키 조작은 InputService `KeyDownEvent`(Client) 기반, 조작마다 모바일 대체 수단 여부는 Open Decision 결정을 따른다.
- **몹 행동 원칙** — 길찾기 비용이 행동을 결정한다: 입구가 뚫려 있으면 진입, 막혀 있으면 최저비용 경로상의 벽을 공격. 지형벽은 파괴·통과 불가.

## Open Decisions (roadmap-level)
- [ ] **이동 명령 입력 방식** — MSW에서 우클릭 구분 인식 가능한지 확인 → 불가 시 대체(어택땅 키+클릭 등). #3 착수 전 확정 (#3, #9 영향)
- [ ] **모바일 지원 범위** — PC 전용으로 갈지, 최소 버튼 UI를 제공할지 (#3, #14 영향)
- [ ] **밸런스 수치 확정** — 경제 테이블(사용자 제시 수치는 가안)·몹 스폰/강화 곡선·보스 스펙·제한시간 (#5, #7, #11, #15 영향)
- [ ] **수익건물 테마** — '밭'은 개념 명칭. 버섯 농장/금광 등 테마 확정 (#16 전; #5는 가칭으로 진행 가능)
- [ ] **전장의 안개** — 기본 미도입. 도입 원하면 신규 유닛으로 추가 (전 유닛 영향이라 늦게 뒤집으면 비쌈)

## Notes / Risks
- **길찾기(#6)가 최대 기술 리스크** — Lua로 그리드 BFS/A*를 돌리는 성능 검증을 #6에서 조기에 실측할 것 (맵 크기·재계산 주기가 여기서 결정됨).
- **풀 RTS 입력(#3)은 MSW 비정형 영역** — 드래그 박스·부대지정은 네이티브 지원이 없어 전부 커스텀. 우클릭 이슈 포함 #3에서 프로토타입 먼저.
- 브레인스토밍 완료·설계 승인 이력: 흐름장 길찾기 방식(A안 수정판)까지 사용자 합의됨 (2026-07-31). 상세 스펙은 각 유닛의 direct 기획에서 작성.
- Maker MCP는 에디터 실행 중에만 연결됨 — 유닛 검증(Play Test) 시 Maker 실행 필요.
