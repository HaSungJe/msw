# 컨셉 피벗 — 벽짓살 → 메이플 운빨 디펜스 (2026-08-02, 사용자 지시)

> 상태: **피벗 선언됨, 순서 지시 대기**. 사용자가 돌아와서 순서대로 지시 예정.

## 새 컨셉 (세션 초반 브레인스토밍 + 이번 지시 종합)
- **메이플 운빨 디펜스** (스타1 유즈맵 원작): 랜덤 유닛 뽑기(운빨) + 같은 유닛 조합/합성으로 상위 등급, 웨이브 디펜스.
- **개인전**: 각자 자기 구역에서 방어. 협동 아님.
- **탈락**: 처리 못 한 몹이 구역에 일정 수 쌓이면 **비석**과 함께 사망.
- 참고: 탈락 연출용 비석 스프라이트 후보를 #14 리소스 스캔 중 발견해둠 (스캔 로그 4a08ebfd… 근처).

## 이번에 확정된 변경 지시 3건
1. **카메라 = F1~F8 단축키(또는 버튼) 시점 전환만** — 유저1~8 구역으로 점프.
2. **맵 크기 = 한 화면(카메라 뷰) × 8** — 1인 구역 = 카메라에 꽉 차는 영역 하나. (뷰 실측 44.5×25유닛 → 예: 4×2 배열 ≈ 178×50유닛. 배열/여백은 기획 때 확정)
3. **자유 카메라 전면 제거** — 마우스 가두기(Confined), 엣지 스크롤, 방향키 스크롤 모두 삭제. 이동 수단은 1번뿐.

## 제안 작업 순서 (사용자가 순서 지시 예정 — 추천안)
1. **로드맵 재편** (`/beaver:roadmap`) — 운빨 디펜스 기준 유닛 재구성 (뽑기/조합/웨이브/구역/탈락 축)
2. **카메라·맵 개편** (direct→build) — 지시 3건 반영: 맵 축소+8구역 구획, F1~F8 시점 전환, 자유 카메라 제거. 미니맵 비율 갱신
3. **뽑기 시스템** — 골드로 랜덤 유닛 소환(등급 확률), 구역 내 배치 (HUD 스킬칸에 '뽑기' 버튼 연결 — SetSkillSlot API 준비돼 있음)
4. **몹 웨이브·순환 경로** — 구역 내 웨이포인트 순환, 누적 카운트, 비석 탈락
5. **조합/합성** — 동일 유닛 N개 → 상위 등급
6. 이후: 유닛 전투(자동 공격), 라운드/보스, 멀티(방), 밸런스, 테마
