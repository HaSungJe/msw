# UI 개선 구현·검증 기록

상태: 승인된 백색 물결 시안과 추가 요청을 게임에 적용했다. Phase 11은 최종 사용자 확인 전이므로 in-progress다. 커밋·푸시는 하지 않았다.

## 최종 적용
- 백색 반투명 패널·흰 물결·은색 테두리·연보라 선택 표시. 채움/테두리를 분리해 투명도를 유지한다.
- 증강 HUD 버튼 하나와 보유/뽑기/도감 탭. 보유는 모든 등급을 함께 표시하며 숨기기는 기존 행을 켜고 끈다.
- 4등급 문양과 속성 아이콘 합성. 직업 프리즘11종은 공식 스킬 그림, 공통 프리즘2종은 속성 그림을 사용한다. 보유·도감·3택1·캐릭터 증강에서 같은 생성기를 쓴다.
- 캐릭터 상세1360×880: 왼쪽 흉상/공식 직업명·레벨, 가운데6축 능력치, 오른쪽 액티브/패시브/증강/버프. 공격속도/방어율 무시는 보조 수치다. 도형 한도를 넘어도 실제 숫자는 유지한다.
- 레벨업/최대 레벨 도달 문구, 증강 아이콘과 본문 영역 분리, 도감 펼친 설명 간격 조정.
- 난이도·프로필·플레이어 카드에 공용 스타일 적용. 솔로 종료의 우측 슬롯 아래 중복 다시하기 제거.
- 새 컨테이너를 투명하게 준비한 뒤 이전 내용과 교대해 반투명 면이 겹치는 밝기 변화를 방지한다. 셸·흉상·수치는 유지하고 같은 탭의 스크롤은 복원한다.
- 썬콜 영입 흉상을 재사용한다. 다른 직업의 임시 원화는 만들지 않았다.

최종 UI 동작에서 추가된 제품 runtime 오류는 관찰되지 않았다. 검증용 execute_script가 잘못된 필드명 AugHideUsed를 사용한 오류1건(03:06:41)은 실제 필드 AugHideAssigned로 수정 후 재검증했다. 01:40:08의 별도 리소스 로드 실패는 이번 검증 전 기록이다.

테스트 유닛·증강·선택지·일시정지는 메모리 fixture다. 확인 뒤 새 Play로 초기화한다. 영구 저장·가격·확률·전투 수치·서버 검증은 변경하지 않았다. RtsAugmentLogic 변경은 UI 목록의 정의 ID 전달과 폐기한 HUD setter 호출 제거다.

## 기록과 범위
- assets/design/ui에는 승인 시안과 실제 공용 자산, resources.json 매핑을 보관한다. 생성 원본은 tools/gen-ui-assets.cjs다.
- docs/design-system.md, docs/ui-screens.md, spec/plan, roadmap을 현재 기준으로 갱신했다.
- .info/artifacts/hud-layout.html은 v45 시각 참고다. 예제 동작/수치는 게임 근거가 아니며 커밋하거나 외부에 재발행하지 않았다.
- 전체 회귀·멀티플레이·모바일 별도 레이아웃·실서비스 출시 검증은 수행하지 않았다.


## 프로필·정렬 추가 수정
- 프로필 설정/연결창과 좌상단 프로필·정보 상자의 투명도를 제거했다.
- 유저 카드를400×96 가로형 한 면으로 정리했다. 왼쪽 아이콘/오른쪽 닉네임은 세로 중앙이며, 각각의 큰 흰 상자를 제거했다.
- 증강 선택의 등급/이름/효과는 가로 중앙 정렬이다. 보유 목록의 이름/미지정은 세로 중앙 정렬이다.
- 대상 유닛 선택은 직업명 왼쪽/레벨 오른쪽 한 줄이다. 유닛 번호를 제거했다.
- Maker 재시작 후 build 오류0·기존 경고8. 불투명 프로필/가로 유저 카드와 보유5개(프리즘 포함)·Lv50/Lv35 대상 버튼의 실제 화면을 확인했다. 새 runtime 오류 없음.
- 선택 카드 정렬은 코드·빌드로 확인했다. 캡처 시 사용자가 선택창을 닫고 플레이를 이어가 최종 선택창 이미지는 확보하지 않았다.
- 사용자가 테스트 정리용 재시작을 승인해 stop → refresh → save → play로 새 세션을 시작했다. 테스트 상태 정리를 확인했다.

## 유저 카드·프로필 목록 후속 수정
- 우측 유닛6칸과 영입 버튼을40 UI px 내렸다. 첫 칸 y=-144, 영입 y=-444. 소스에 저장하고 기존 UI 좌표에도 적용했다. 사용자 요청으로 stop → refresh → save → play 후 build 오류0·기존 경고8, UNIT_LIST_RESTART 로그에서 새 세션의 첫 칸·영입 위치를 확인했다.
- 각 사용자 테마 썸네일을 비율 유지·마스킹해 카드 배경으로 표시했다. 닉네임은 오른쪽 정렬, 내 카드에는 초록 테두리·마름모 문양을 넣었다.
- 좌상단 정보에서 난이도 줄을 없애 상자 높이를208로 줄였다. 아이콘 목록은 엔진 기본 격자 크기로 겹치던 문제를 명시적인6열 행으로 수정했다. 썸네일 아래 별도 이름 영역을 실제 화면에서 확인했다.
- 프로필 확인창을 별도 레이어로 구현해 기존 목록을 유지한다. 아이콘 정보가 기존 프로필 위에 표시되는 화면을 확인했다. 사용자 조작이 겹쳐 확인→취소 후 스크롤 보존의 전체 경로는 아직 검증하지 못했다.
- 이 단계 Maker build 오류0·기존 경고8, normal 신규 오류 없음. 게임 데이터 fixture는 생성하지 않았다.
- 마지막 추가 변경: 아이콘 행 여백10, 정보창의 보유 상태 갱신, 난이도 선택을 idle·countdown에만 표시, 다시하기를 상단 y=-12로 이동. 바로 시작은 y=-114 유지. diff 공백 검사는 통과했다.
- 사용자 재시작 승인 후 stop → refresh → save → play로 마지막 추가 변경까지 적용했다. build 오류0·기존 경고8, 신규 runtime 오류 없음. 03:58:44 클라이언트 실측: running에서 difficulty=false, restart=true, restartY=-12. 아이콘 행 여백과 확인→취소 스크롤 보존의 최종 화면 경로는 별도 미검증이다.
