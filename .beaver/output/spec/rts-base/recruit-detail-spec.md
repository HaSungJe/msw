## Feature Description
사용자 2026-09-25: "영입창에서 유닛 선택하면 팝업 나와서 유닛 기본 외형 + 설명(캐릭터 컨셉. 초반 약하고 후반 강하다는 등의 설정) + 강점 + 약점 스탯 등이 오각형으로 나오게.
사거리/크리티컬 확률/크리티컬 데미지/공격력(기본/성장 공격력/공격력/공격력%) — 증강X + 50레벨 기준. 그리고 영입/취소 버튼. 영입 누르면 영입하고, 취소 누르면 유닛 목록 창."
같은 메시지: "난이도 선택창 화면 최상단에 붙게."

지금은 영입 목록 카드를 누르면 곧바로 발판 고르기(배치 모드)로 넘어가 직업을 비교할 방법이 없다. 상세 팝업이 그 사이에 들어간다.

## 진입점
- Method: 클라 팝업(ClientOnly) — 서버 호출 없음. 영입 자체는 기존 흐름(발판 클릭 → `RtsUnitLogic.RequestRecruitAt`, Server·senderUserId 검증)
- Path: 영입 창(`recruit`) 카드 클릭 → `RtsPopupLogic.PendingJob = jobId` → `Open("recruitinfo")`
- Request: 직업 id(hero·paladin·dk·bow·marks·il·fp·bishop·nl·shad·phantom)
- Response: 팝업 표시. [영입] → 창 닫고 `RtsUnitSelectLogic.BeginPlace(jobId)`(지금 카드 클릭이 하던 일 — RtsPopupLogic:478-481), [취소] → `Open("recruit")`(목록으로)

## Business Rules
- **모든 직업 카드**(보유 중·잠김·지금 영입 불가 포함)를 누를 수 있다 — 보기만. **[영입]은 지금 영입 가능할 때만**(영입 한도 남음 · 카운트다운/진행 중 · 살아 있음 · 해금 · 미보유 — 목록의 기존 판정 그대로). 안 되면 [영입] 대신 이유 한 줄("보유 중" / "잠김 — 팬텀 프리즘으로 해금" / "지금은 영입할 수 없음" / "다음 영입 n라운드").
- 팝업 내용
  1. **외형**: 기본 스킨(모험가 직업 세트) 아바타 — 유닛 정보 창 미리보기(`RtsUnitPopupLogic.SpawnPreview` :884-)와 같은 UI 아바타
  2. **이름 · 계열**(전사/궁수/마법사/도적/영웅) · **설명** 2~3줄(아래 초안 — 사용자 검토 뒤 확정)
  3. **오각형** 5축: **공격 속도 · 사거리 · 증강 효율 · 보스 · 사냥**, 축마다 **매우 높음 / 높음 / 보통 / 낮음 / 매우 낮음** 5단계(꼭짓점 = 단계 ÷ 5). 축 이름 옆에 단계 글자
  4. **능력치(50레벨 · 증강 없음)**: 사거리 n칸 · 크리티컬 확률 · 크리티컬 데미지 · 공격력 — 기본 · 성장(레벨당) · 50레벨 공격력 · 공격력% (그 밖에 공격 속도 이름)
  5. 버튼 [영입] [취소]
- 오각형 단계(사용자 "모든 항목 5단계", "전체 직업 중 비교")
  - **공격 속도**: 매우빠름 → 매우 높음 · 빠름 → 높음 · 보통 → 보통 · 느림 → 낮음 · 매우느림 → 매우 낮음(50레벨 기본 공격 속도)
  - **사거리**: 50레벨 기본 공격 사거리를 전체 직업 최댓값에 대한 비율로 — 80% 이상 매우 높음 · 60% 높음 · 40% 보통 · 20% 낮음 · 그 아래 매우 낮음
  - **증강 효율**(사용자 "1티어는 매우 높음, 2티어는 보통, 서포터는 매우 낮음 … 낮음 단계가 없지만 5단계로"): 히어로·나이트로드·썬콜·보우마스터 = 매우 높음(증강 ×3 계열) · 팬텀 = 높음(모든 증강 ×1.75) · 섀도어·불독·신궁·다크나이트 = 보통(약점 증강 ×2) · 비숍·팔라딘 = 매우 낮음. '낮음'은 비어 있음. 화면엔 티어라는 말을 쓰지 않는다(메모리 workflow)
  - **보스**(사용자 "최대 효율 증강 기준 — 성장 포텐"): 50레벨 + 자기 직업 프리즘 + 마지막 보스 시점까지 받을 증강을 그 유닛에 전부 최대 효율로 몰아준 보스 DPS를 전체 최댓값 비율로 5단계
  - **사냥**(사용자 "사냥 능력 기준"): 50레벨 · 증강 없음 몬스터 DPS(타겟 수 포함, 공격 루프 기준)를 전체 최댓값 비율로 5단계
  - 보스·사냥·사거리 단계는 `tools/balance-calc.py`(게임과 같은 표 기준 계산기)로 계산해 직업 표에 상수로 넣는다 — 직업 수치가 바뀌면 다시 돌린다
- 직업 설명 초안(2~3줄, 사용자 검토 — 틀린 성향은 알려 주면 고친다)
  - 히어로: 두손검으로 앞의 적 여럿을 베는 근접 딜러. 초반은 무난하고, 40레벨부터 한 번에 베는 수가 늘며 50레벨 발할라로 보스를 크게 친다. 증강을 몰아줄수록 끝없이 강해지는 주인공.
  - 팔라딘: 해머를 느리게 휘두르는 수호자. 혼자 딜은 약하지만 40레벨 가드 크러쉬로 구역 적의 방어율을 깎아 팀 전체 딜을 끌어올린다.
  - 다크나이트: 창으로 세 번 찌르는 느리고 묵직한 전사. 초반은 평범하지만 후반 거대화 프리즘으로 보스를 강하게 친다. 크리티컬은 약하다.
  - 보우마스터: 매우 빠른 연사로 한 마리씩 빠르게 녹이는 궁수. 사냥이 안정적이고 증강을 받을수록 폭풍의 시가 보스까지 녹인다.
  - 신궁: 멀리서 저격하는 명사수. 사거리와 확정 크리티컬이 강점이지만 기본 공격력과 크리티컬 데미지는 약해 증강으로 채워야 한다.
  - 아크메이지(썬·콜): 체인 라이트닝으로 여럿을 잇고 블리자드로 얼려 느리게 만드는 마법사. 사냥과 보스를 모두 책임지는 딜러로 증강 효율이 높다.
  - 아크메이지(불·독): 독 안개로 트랙 전체에 지속 피해를 까는 광역 사냥꾼. 공격력은 강하지만 크리티컬은 약하다.
  - 비숍: 빛으로 팀을 돕는 서포터. 30레벨 프레이로 구역의 모든 유닛 최종 데미지를 올린다. 혼자 딜은 약하다.
  - 나이트로드: 빠른 표창 연타의 암살자. 스킬에 공격력%·보스 데미지가 없어 증강을 받을 때 효율이 가장 좋다 — 후반형.
  - 섀도어: 크리티컬에 특화된 단검 도적. 크리티컬 확률·데미지는 강하지만 기본 공격력이 약하다.
  - 팬텀: 모든 증강이 고르게 잘 붙는 만능형. 조커로 아군 전체의 최종 데미지를 조금 올린다. 팬텀 프리즘을 얻어야 영입할 수 있다.
- 난이도 창: 지금 화면 위에서 88px 아래(영입 버튼 자리 밑 — RtsDifficultyLogic:159 `Vector2(0, -88)`) → **화면 최상단에 붙인다**(y 0). 크기·내용 그대로

## Notes
- 영입 목록 카드의 흐림·'보유 중'·'잠김' 표시와 영입 가능 판정(RtsPopupLogic:437-470)은 그대로 쓰고, 클릭만 모든 카드에 붙인다.
- 오각형은 MSW UI에 도형 그리기가 없어 스프라이트로 만든다: 바탕 그물(오각형 5겹 + 축 5개)은 PNG 한 장, 값 다각형은 흰 직각삼각형 스프라이트 10장(삼각형 5개를 높이선으로 둘씩 나눔 — 회전·가로세로 크기만으로 어떤 삼각형이든 된다) + 테두리 선 5개. 새 자산 2개(업로드는 build 단계).
- 설명·오각형 단계는 클라가 직업 표(`RtsJobTableLogic`)에서 읽는다 — 서버 상태·동기화 없음.
