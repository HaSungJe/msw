## Feature Description
로드맵 "결정 대기 #1~#3"(UI 배치·그리드 트랙·미니맵 삭제)이 **아티팩트 v16**(`.info/artifacts/hud-layout.html`, claude.ai/code/artifact/dfb49cfc-c83f-485c-b0b5-b91fc04cd701)으로 확정됐다. 이 기능은 그 목업을 **실제 게임 화면으로 옮기는 것**이다. 데이터 테이블(Phase 2)·유닛(Phase 4)·영입/증강 로직(Phase 5·6)은 아직 없으므로, 이번에 만드는 것은 **무대(트랙·발판)와 HUD·팝업의 "껍데기"** — 보이는 것과 좌표계는 완성, 숫자와 동작은 뒤 페이즈가 채운다.

### 1. 무대 — 그리드 트랙 (스타디움 트랙 폐기)
- 구역 하나 = **화면 하나**(42.66×24). 이제 HUD가 하단을 가리지 않으므로 구역이 카메라 뷰 전체를 쓴다. 카메라 앵커는 구역 정중앙(Y 오프셋 0).
- 구역 안에 **18열×12행 그리드**(칸 1.78유닛 = 화면 80px). 그리드는 목업과 동일하게 화면 왼쪽 300px·위 80px 지점에서 시작(구역 중앙 기준 좌 −14.67, 상 +10.22).
- **트랙** = 목업의 경로 그대로. 시작 S=(3열 6행)에서 위로 4칸 → 2행을 따라 동쪽 → … → 끝 E=(3열 12행). 총 66칸 이동, **길이 117.3유닛**, 지나가는 칸 65개(교차 2칸: 12열 6행·12열 8행). E에 닿은 몹은 **S로 순간이동**(왼쪽 점선 화살표가 그 표시). 경로 좌표는 `t∈[0,1]`(0=S, 1=E)로 질의 — 스타디움 때의 t 규약(둘레 정규화)을 "구간 정규화"로 바꾼다.
- **발판** = 트랙 칸에 상하좌우로 면한 칸 **81개**. 유닛은 발판에만 1기씩 선다(트랙 칸·면하지 않은 칸은 불가). 발판은 연한 회청 채움+테두리, 그 외 빈 칸은 얇은 테두리만(목업 그대로).
- **사거리 규약**(좌표계에만 기록, 실제 사용은 Phase 4): 8방향 칸 거리 = 열·행 차이 중 큰 값. 전사 1·마법사 2(광역 6)·도적 2·궁수 4.
- **그리기**: 구역마다 트랙+발판+S/E+복귀 화살표가 든 **텍스처 1장**(1440×960px, 칸 80px)을 스프라이트로 얹는다(스타디움 때와 같은 방식 — 프롭 1개/구역). 트랙 칸 재질은 **헤네시스 돌길 포석**(사용자 확정 2026-08-18)에 목업의 흰 점선 진행선을 얹는다. 구역 경계선 4장은 **제거**(구역 = 화면이라 경계가 화면 밖).
- **보스**: 별도 맵 없음. 보스 스테이지가 되면 구역 화면 중앙(그리드 기준 9~10열·6~7행 사이)에 등장 — 이번엔 자리만 정의(`GetBossPoint(zone)`), 생성은 Phase 7.

### 2. HUD v2 (기존 스타식 HUD 전부 교체)
- **삭제**: 하단 바 전체(미니맵 340·초상화 240·선택유닛 정보·스킬칸 3×3·툴팁), 부대지정 탭 10개와 Ctrl+숫자 처리, 상단 중앙 시간 패널, 좌상단 골드 패널.
- **좌상단**: 세로로 **시간 칩 → 메소 칩**. 시간은 Phase 3이 채울 때까지 `--:--`, 메소는 `0`. 갱신 API만 열어 둔다.
- **좌측 플레이어 목록**: 헤더 `n / 8`(현재 인원), 행 = 생존 점(초록) + 닉네임. **나**는 금색 세로 바 + `(나)`. 탈락은 회색 테두리 + 비석 아이콘(이번엔 상태 API만, 실제 탈락은 Phase 3 #13). 지금 **보고 있는 구역**의 사람은 밝게. **행 클릭 → 그 사람 구역으로 카메라 이동**(미니맵 클릭 대체). F1~F8은 그대로 유지.
- **우측 열**: `영입` 버튼 + 그 아래 **유닛 슬롯 6칸**(영입 순서 번호·직업·Lv). 지금은 전부 `빈 자리`. 슬롯 클릭 → 그 유닛 발판에 금색 링(유닛이 생기는 Phase 4에서 연결, 이번엔 슬롯 채우기/비우기 API까지).
- **좌하단**: `증강` 버튼.
- **우상단 MSW 시스템 버튼**은 엔진 제공 — 손대지 않는다.

### 3. 팝업 셸 (공통 셸 + 3종 내용)
- **공통 셸**(`RtsPopupLogic`): 화면 전체 어둡게(딤) + 중앙 패널(금색 테두리, 제목, 닫기 ✕). 딤 클릭·✕·ESC로 닫힘. 한 번에 하나만. 로드맵 #18이 말한 "이후 모든 팝업의 공통 셸"을 여기서 먼저 만든다.
- **영입 팝업**: 상단 직업군 탭(`모험가`, 그 옆 `…` 자리), 아래 4계열(전사·궁수·마법사·도적) 묶음으로 **직업 10종 카드**(이름 + 다음 영입가). 푸터 `보유 0 / 6`. 카드 클릭은 아직 아무것도 안 함(영입은 Phase 5).
- **증강 팝업**: 세로로 긴 패널. 탭 `전체/브론즈/실버/골드/프리즘`(개수 배지), 왼쪽 스크롤 목록, 오른쪽 상세(등급 배지·이름·설명·적용 유닛). 지금은 목록이 비어 `아직 없음` 안내. 미지정 `!`·대상 1회 지정 UI는 목록에 항목이 생기는 Phase 6에서.
- **보스 처치 3택1 팝업**: 카드 3장(등급색 상단 띠·등급 배지·이름·설명·대상 유닛 칩 5개·`대상 없이 수령` 버튼). 닫기 없음. 실제 트리거는 Phase 6/7 — 이번엔 **미리보기 단축키**(`B`)로만 열어 확인한다(내용은 예시 3장).

## Entry Point
- Method: Server(입장 시 트랙 시각화 1회 생성 + 플레이어 목록 통지 / 퇴장 시 통지) · Shared(그리드↔월드 좌표, 트랙 t→좌표, 발판 목록) · Client(HUD 생성·갱신, 팝업 열기/닫기, 목록 클릭→카메라)
- Path:
  - `RtsConfigLogic` — 구역 42.66×24(피치 48×32 유지), `GridCols/GridRows/GridCell`, 그리드 원점 오프셋, 카메라 오프셋 0
  - `RtsZoneLogic` — `GetTrackPoint(zone,t)`(구간 정규화)·`GetTrackLength()`·`GetSpawnPoint`·`GetEndPoint`·`GetCellCenter(zone,col,row)`·`IsRoadCell`·`IsPadCell`·`GetPadCount`·`GetPlacementSlot(zone,index)`(=발판 index)·`CellDistance`·`GetBossPoint(zone)`·`EnsureZoneVisuals`(그리드 텍스처 1장/구역)
  - `RtsHudLogic` — `BuildHud`·`SetTime(text)`·`SetMeso(n)`·`RefreshPlayerList(...)`·`SetPlayerAlive(userId,bool)`·`SetWatchedZone(n)`·`SetUnitSlot(i,...)`·`ClearUnitSlot(i)`
  - `RtsPopupLogic` — `Open(kind)`·`Close()`·`IsOpen()` + 영입/증강/3택1 내용 빌더
  - `RtsCameraAnchorComponent` — `JumpToZone`이 `SetWatchedZone`을 부름(미니맵 갱신 대체)
  - `RtsBootstrapLogic` — 배정/해제 뒤 전 클라에 목록 갱신 통지
- Request: 유저 입장/퇴장, 좌표 질의(t·칸), 버튼 클릭(영입/증강/슬롯/목록 행), 단축키(F1~F8·ESC·B)
- Response: 월드 좌표, HUD/팝업 엔티티 생성·갱신, 카메라 이동

## Business Rules
1. **좌표 단일 소스**: 그리드↔월드 변환·트랙 t·발판 목록은 전부 `RtsZoneLogic`. 원시 수치(칸 크기·원점·구역 크기)는 `RtsConfigLogic`. 다른 스크립트가 칸 좌표를 직접 계산하지 않는다.
2. **트랙 t 규약 변경**: `t=0`=S, `t=1`=E, 그 사이는 경로 길이 비례(등속). 1을 넘기면 E에 고정(순환은 몹 로직이 t를 0으로 되돌려 처리 — Phase 3). 스타디움의 "둘레 정규화·반시계" 규약은 폐기.
3. **발판 규칙**: 트랙 칸에 4방향으로 면한 칸만 발판(81개). 발판 index는 행 우선(위→아래, 왼→오른). 트랙 칸·비면접 칸은 배치 불가.
4. **8방향 거리**: 두 칸의 거리 = max(|Δ열|, |Δ행|). 사거리 판정은 이 값 ≤ 사거리.
5. **구역 = 뷰**: 구역 42.66×24, 카메라 오프셋 0. 배치 피치 48×32는 그대로(맵 96×128, 바닥 타일 계산 불변).
6. **HUD 갱신은 API 경유**(Cross-Cutting): 시간·메소·플레이어 상태·슬롯은 전부 `RtsHudLogic`의 Set/Refresh로만 바뀐다.
7. **플레이어 목록 = 배정 현황**: 행은 `RtsZoneLogic.ZoneByUser`(구역 번호순). 서버가 배정/해제 직후 전 클라에 갱신을 통지하고, 통지에 유저별 닉네임·구역·생존을 같이 실어 보낸다(동기화 지연에 의존하지 않기 위해). 생존은 이번엔 항상 true.
8. **팝업은 한 번에 하나**: 열려 있는 상태에서 다른 버튼을 누르면 먼저 닫고 연다. 3택1은 닫기 없음(ESC·딤 무시).
9. **삭제 규칙(§1.7)**: 스타디움 트랙 텍스처·경계선·`TrackSignedDistance`·`IsInPlacementArea`·미니맵·스킬칸·툴팁·부대지정·`SetSkillSlot/ClearSkillSlots/UpdateMinimapZone/OnMinimapClick`·Ctrl 키 핸들러는 코드에서 제거(기록은 git 히스토리). 텍스처 파일·생성기는 `assets/textures/README.md`에 "보관"으로 남긴다.

- `.info/artifacts/hud-layout.html`이 시각 기준. 빌드 중 화면과 목업을 나란히 놓고 맞춘다. 페이즈 완료는 사용자 만족 루프(`.beaver/memory/workflow.md`).

## Decisions
- [x] **트랙 칸 재질** — 헤네시스 돌길 포석 + 흰 점선 진행선. 근거: 사용자 확정 2026-08-18("헤네시스의 돌배경은 트랙"), 목업의 베이지는 SVG 임시색.
- [x] **구역 경계선 제거** — 구역 = 화면이라 경계가 보이지 않음. 코드·스프라이트 삭제.
- [x] **발판 = 트랙 4방향 면접 칸(81)** — 사용자 지시 "트랙 주변의 발판에". 비면접 칸은 배치 불가(목업의 연한 칸).
- [x] **기존 HUD 요소 전면 삭제**(숨김 아님) — 스킬칸·부대지정·미니맵·초상화·툴팁. 목업에 없고 스킬은 유닛 팝업(Phase 5 #20)으로 간다. 근거: 사용자 "미니맵과 같은 아래쪽 영역의 요소들 모두 제거".
- [x] **F1~F8 유지** + 플레이어 목록 클릭 추가. 근거: 로드맵 Non-Goals "F1~F8 시점 전환".
- [x] **3택1 팝업은 미리보기 단축키(B)로만** — 트리거(보스 처치)는 Phase 6/7. 단축키는 Phase 6에서 제거.
- [x] **영입 카드의 가격 표시**는 Phase 2 경제표(무료·500·2,000·5,000·10,000·30,000)를 그대로 보여 주되 **문자열 상수**로 두고, Phase 2 테이블이 생기면 그쪽을 읽도록 교체.
- [x] **시간 칩에 스테이지 번호는 아직 없음** — Phase 3 #9가 "스테이지 n · 지역명" 표기 위치를 정할 때 같은 칩을 넓힌다.
