## 2. 증강 합류 (로드맵 Phase 4 #14·#15·#16 나머지·#17 — 사용자 "증강 선택도 여기서 만들어버리자")

### 결정 (사용자 2026-09-23 + 기존 확정)
- 지급: 브론즈~골드 = 지급 라운드(augmentation.md 태그 표) **시작 때** 3택1 팝업, 프리즘 = 자쿰·시그너스·스우·루시드·진 힐라 **처치 직후**. 닫기 없음(하나를 골라야 닫힘), 게임은 뒤에서 계속.
- 후보 3장은 서로 다름, 확률 = augmentation.md 가중치. 브~골은 중복 획득 가능. 프리즘 중 직업·팬텀은 한 번 고르면 다시 안 나옴, 특수 코어 3종(일격필살·보스 슬레이어·방어구 부수기)은 중복 등장 가능·같은 유닛 중복 적용 불가. 후보엔 미보유 직업 전용도 나온다(11직업 + 팬텀).
- 받을 때는 대상 미지정 → 증강 창에서 유닛 1명에 **1회 지정**(바꿀 수 없음). 직업 프리즘은 그 직업 유닛에만, 팬텀은 받는 즉시 영입 해금. 좌하단 버튼 `증강(n)` = 미지정 수.
- 효과(전부 합연산, damage.md): 크리 확률·크리 데미지·공격력 +n·공격력 %·보스 공격시 데미지 → 능력치 오버레이(GetStatFor), 일격필살 = 최종 ×1.15, 방어구 부수기 = 방무 +30.
- 유닛 방출 = 그 유닛에 지정된 증강 소멸(기존 규칙). 탈락·새 판 = 보유 증강 초기화.
