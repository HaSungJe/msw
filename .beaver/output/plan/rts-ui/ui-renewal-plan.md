## Design

1. 백색 반투명 패널·흰 물결·얇은 은색 테두리·연보라 선택 표시를 공용 스타일로 사용한다. 승인 시안은 `assets/design/ui/concept-white-wave.png`다.
2. 캐릭터 상세1360×880 안에서 흉상/공식 직업명·레벨은 왼쪽, 6축 능력치 도형은 가운데, 액티브/패시브/증강/버프는 오른쪽이다. 수치는 게임의 최종 계산 결과를 표시한다. 공격속도·방어율 무시는 보조 행으로 남긴다.
3. 증강은 하나의 HUD 버튼과 보유/뽑기/도감 탭이다. 보유 등급 탭은 없애고 모든 등급을 한 목록에 표시한다. 숨기기는 기존 행을 켜고 끄며 셸·목록을 재생성하지 않는다.
4. 브론즈/실버/골드/프리즘의 문양 바탕과 속성 그림을 합성한다. 직업 프리즘11종은 공식 스킬 그림, 공통 프리즘2종은 속성 그림을 쓴다. 도감·뽑기·보유·캐릭터 증강에서 같은 도우미를 사용한다.
5. 3택1은 같은 크기의340×660 카드, 아이콘104px, 이름과 전체 설명, 하단 받기 버튼이다. 긴 설명3종에서 겹침을 확인한다.
6. 난이도·프로필·유저 카드도 공용 스타일로 맞춘다. 솔로 종료의 중복 다시하기를 숨긴다. 레벨업은 ‘레벨업’/‘최대 레벨 도달’로 표시한다.
7. 내용 교체는 새 면을 투명하게 준비한 뒤 이전 면과 교대한다. 정적인 셸을 다시 열지 않으며 같은 탭의 스크롤을 복원한다.

## Response Codes

HTTP 응답은 없다. 가격·확률·게임 규칙·저장·서버 요청 검증은 기존 로직을 따른다. 검증 기록과 미확인 범위는 report에 남긴다. 형식적인 UI 모사 테스트 파일은 만들지 않는다.

## 추가 반영
프로필 불투명화, 유저 카드400×96 좌우 배치, 3택1 가로 중앙 정렬, 보유 증강 이름/미지정의 세로 중앙 정렬, 대상 직업명/레벨의 한 줄 배치를 적용한다.

각 사용자 테마 배경·오른쪽 닉네임·내 카드 문양, 프로필 확인창 중첩, 아이콘6열 독립 배치, 시작 전 난이도/하단 바로 시작과 진행 후 상단 다시하기를 반영한다.
