# 증강·경제·방어율 개편 계획

- 요청: 2026-10-14 사용자 패치 목록(증강 지급 팝업 · 레벨업 비용 · 방무/방어율 · 도트 퍼니셔 · 초월/템페스트 · 체인 라이트닝 · 프레이 · 증강 개편) + 같은 날 추가(뽑기 6,000 · 최대 레벨 100 · 영입 12명/비용 · 티어 삭제 · 보스 체력 · 대상 아닌 유닛 숨김)

## 1. 증강 얻기·고르기
- 라운드마다 주던 브론즈·실버·골드(17개)를 없앤다. 프리즘은 자쿰·시그너스·루시드 처치 보상 그대로.
- 뽑기 6,000메소 고정. **등급 = 일반 · 프리즘 둘뿐**(같은 날 사용자 "증강 브론즈/골드/실버를 다 없애자. 그냥 일반증강 95% 프리즘5%. 저거 다 전체중에 랜덤하게 나오게해줘"): 프리즘 5% · 나머지 95% 일반.
- I/II/III 단계 없음. 일반 선택지 = 공통 3 + 직업 24 = 27종 전체에서 서로 다른 무작위 3장(가중치 같음) 중 1개 — 내가 가진 직업이 아닌 직업 증강도 나온다(그 직업을 영입하면 지정, 아니면 보유에 미지정으로 남음). 처음 열 때 만든 3장은 다시 열어도 그대로. 사용자 선택: 공통 3종 그대로 섞기 · 무작위 3장 중 1개 선택 · 후보 = 전체 직업 · 보스 체력은 그대로.
- 화면: 뽑기 탭 카드 2장(일반 95% '공통·직업 증강 27종 중 무작위 3장' / 프리즘 5%), 도감 탭 일반 27 · 프리즘 11, 선택 카드 머리 글자 '공통' / '<직업> 전용' / '프리즘', 미선택 행 '일반 증강' / '프리즘 증강', 일반 문양·색 = 전 실버. 코드 id에서 등급 접두어 삭제(all_1~3 · hero_rb … ph_joker).
- 이력 — 같은 날 앞선 안: 등급 = 프리즘 5% · 나머지 브론즈 50 / 실버 40 / 골드 10, 뽑은 등급의 선택지 = 그 등급의 공통 증강 1종 + 그 등급에 배치된 직업 증강 중 내 유닛 직업 것.
- 받거나 사도 선택 창이 저절로 열리지 않는다(HUD 미선택 개수·증강 버튼 반짝임만).
- 유닛당 증강 개수 한도 없음.
- 증강을 지정할 때 받을 수 없는 유닛은 캐릭터 칩·받을 유닛 목록에서 숨긴다(흐리게 두지 않음). '지정 안 함'은 남긴다.
- 삭제: 기존 브~골 증강 37종(약점 찾기·급소 찌르기·무기 연마·전투 감각·거인 학살자), 특수 코어(일격필살·보스 슬레이어), 여러 장 체크·최적화 자동선택·전체선택.

## 3. 프리즘
- 직업 프리즘(듀얼블레이더 포함)은 50레벨 유닛에게만 지정 가능. 50 미만 유닛은 대상 목록에서 숨긴다.
- 프리즘의 방무 +70(템페스트·풍마수리검)·증강 효율·방어구 부수기 삭제.
- 프리즘 유무 차이 1.2~1.5배(50레벨·같은 증강·보스 DPS): 인레이지 3회만(비율 추가 없음) · 홀리 유니티 그대로 · 거대화 1회 +30% · 애로우 레인 65%×2·보스 +100% · 트루 스나이핑 쿨 6초·370% · 템페스트 쿨 5초·일반 365%·보스 58%×30 · 초월 구체 30·쿨 6초·177% · 디바인 퍼니시먼트 127% · 풍마수리검 154% · 듀얼블레이더 52%×72 + 55%×45·보스 +56%·크뎀 +80%(크확 보너스 삭제).
- 템페스트 쿨이 길어져 체인 라이트닝이 사이사이 나간다(지금은 쿨 2초·후딜 1.8초라 체인 라이트닝이 끼어들 틈이 없었다).

## 4. 방어율
- 50레벨 패시브 방무 삭제(발할라·폭풍의 시 강화·피어싱 강화·드래곤 로어·불독 인피니티·레디 투 다이·블스아이). 히어로 콤보 어택 5·10, 팔라딘 가드 크러쉬는 유지.

## 5. 체력(생성기 tools/gen-stage-table.py로)
- 보스 기준 체력 배율: 주니어 발록~시그너스 ×0.8 · 스우·데미안 ×1.04 · 루시드 ×1.53 · 윌 ×2.39 · 더스크 ×2.90 · 진 힐라 ×3.53 · 듄켈 ×4.37 · 검마 ×5.16/×5.16/×4.95/×6.27.
- 일반 몬스터 = 그 구간 보스(다음에 나오는 보스)와 같은 배율.
- 근거: 12명(팔라딘 + 비숍 + 딜러 10명) 새 규칙 모의실험 팀 딜 ÷ 지금 체력 기준 팀(6명 모델) 팀 딜 × 0.8. 플레이로 다듬는 전제.
- 플레이 뒤 수정 1(같은 날, 사용자가 주니어 발록까지 플레이): "레벨업이 쉬워져서 체력이 너무 낮다, 3배" → 주니어 발록~시그너스 구간(보스·일반 몬스터)만 ×3(배율 0.8 → 2.4). 스우·데미안 구간 일반 몬스터(57~63)도 2.4로 맞춰 55 → 57에서 체력이 줄지 않게 했다.
- 플레이 뒤 수정 2(같은 날): "시그너스 → 스우로 넘어갈 때 체력이 확 뛰는 건 문제, 2배로 줄이고 주니어 발록~시그너스를 점진적으로" → 게임 안 체력(표 × 극악 곡선) 경사로(생성기 RAMP_MUL).
