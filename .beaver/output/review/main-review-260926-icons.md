## 의도 확인
- 일반 몬스터와 보스에 동일한 난이도별 확률이 적용된다. 1~4 난이도는 0이다.
- 아이콘 상세 확률: 처치 시 확률: 매우어려움 1% / 극악 2%.
- 획득처: 매우어려움 / 극악 + 최초 등장 라운드·지역·맵.
- 실제 확률 실행 및 화면 렌더링은 아직 재생 검증하지 않았다. 편집 모드 빌드 확인과 코드 참조 검토만 수행했다.
- 진행 중 별도의 스킬 설치·설정 변경이 발생했다. 관련 설정·설치 파일 및 실행 로그는 이번 커밋에서 제외하고 작업 트리에 보존한다.
