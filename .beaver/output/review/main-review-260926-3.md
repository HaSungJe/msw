# 검토 — 유닛 모션·증강·화면 개선

## 대상
- main 직접 작업, 사용자 커밋·푸시 승인.
- 히어로·비숍 외형 연결, 원화 4직업 대기·공격 프레임 확장, 블리자드 1.8초, 도트 퍼니셔 5초 만료 연출.
- 미선택 증강 개별 목록·선택·수령, 구매 탭 분리, HUD 글꼴·난이도·유닛 목록 및 몬스터 상태창 개선.
- 관련 최종 PNG·연결표·설계 문서·검증 기록 포함. 미승인 직업 시안, 추출 캐시, 업로드 임시 정보, 로컬 로그·설정은 제외.

## 동작·검증 근거
- Maker에서 원화 4직업의 13개 액션 재생 및 대기 복귀 확인. 66개 PNG 규격·투명도·해시와 연결 정보 검산 완료.
- 히어로 일반 불꽃 월드 배율 2.0, 인레이지 7프레임에서 일반 검 이펙트 Visible=false 확인. 사용자가 인레이지 재생 확인 완료.
- 블리자드 템페스트는 2초 간격 시전 중 1.85초 검사에서 대기 복귀.
- 도트 퍼니셔는 생성 후 5.05초에 구체 제거·현재 위치 적중 클립 생성, 6.5초에는 폭발도 제거됨.
- 미선택 7건 중 골드 선택 → 받기 버튼 이벤트 → 보유 1·미지정 1·미선택 6 → 유닛 4 지정 확인. 오래된 수령 요청은 중복 지급되지 않음. 10건 상한·오래된 건 제거·후보 유지 확인.
- 사용자 조작이 함께 진행된 탭 유지 자동 확인 1건은 assertion 실패로 남아 단독 검증 결과로 사용하지 않음. 구매 화면은 실제 화면에서 확인. 기존 RefreshDraw nil 오류는 생성 완료 검사로 보완.
- 최종 재시작: 빌드 오류 0·경고 10, 실행 오류 0. paused=false·previewTimerCleared=true·pending=0·owned=0 확인. git diff --check 통과.
- CLI mLua 테스트/컴파일 명령은 없음. 기존 Maker 빌드 로그를 문법 검사로 사용하며 전체 회귀 시험을 주장하지 않음.

## 판정
현재 변경 범위에서 차단할 사항 없음. 코드·자산 커밋 후 원격 main에 푸시한다. UI 디자인 패스(#36) 완료 상태는 별도 로드맵 커밋으로 기록한다. 워크트리 정리는 해당 없음.
