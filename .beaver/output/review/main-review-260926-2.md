## 대상
- direct 모드: `main` → `origin/main`, 예정 버전 `v260926-5`.
- 범위: 게임 스크립트 6개, 불독 결과물 PNG 8개, 적용·UI·제작 규칙 문서 및 버전 표기.

## 의도 대조
- 승인한 불독 외모·의상을 기준으로 대기 1장, 포이즌 리전 3장, 도트 퍼니셔 3장과 별도 흉상을 연결했다. 기본 아바타를 처음부터 생성하지 않아 외형 전환 번쩍임을 피한다.
- 포이즌 리전: 수직 들어 올리기→무릎을 굽혀 바닥 찍기→회복. 0.40/0.45/0.35초, 내려찍는 시점에 독 이펙트와 시전음.
- 도트 퍼니셔: 한쪽 위→머리 위 원호→반대편 휘두르기. 0.35/0.40/0.45초. 구체 표시 지연만큼 대기를 줄여 기존 발사·판정 시각 유지. 초월은 같은 프레임을 상속한다.
- 썬콜 프레임·시간표와 나머지 아바타 직업의 경로는 유지한다. 모든 변경된 조회 호출은 jobId를 전달한다.
- 후속 요청을 반영해 직업군 제목을 열 중앙에 정렬하고 영입 레벨 표시를 제거했다. 창1014×660·카드182.4×132로 줄이고 캐릭터·직업명의 세로 위치를 조정했다. 보유·잠김 상태는 별도로 유지한다.
- 모든 계열에서 전사/궁수/마법사/도적/해적 열을 유지한다. 해적 등 빈 열은 출시 예정, 팬텀은 영웅의 도적 열이다. 새 계열도 같은 5열 생성 경로를 사용한다.
- 임시 백업은 사용자 채택 후 삭제했다. 캐릭터 폴더에는 최종 PNG 8개만 남겼다.

## 검증 근거
- Maker stop→refresh→save→play: 빌드 오류 0, 기존 경고 8.
- 실제 전투의 클라이언트 로그에서 dotPunisher 3개 RUID, poisonRegion 3개 RUID, stand1 복귀 확인. 런타임 오류 0.
- 모험가/영웅/미등록 계열의 반환 열 수 5와 열 이름·순서 검사 통과. 모험가와 영웅 탭의 실제 화면 배치 확인 후 확인용 창을 닫았다.
- 초기 외형 연결 검증에서 썬콜 블리자드의 기존 3프레임과 3초 시전 회귀, 불독·썬콜 기본 아바타 미생성, 선택·상세 흉상을 확인했다.
- CLI용 mLua 검사기는 없다. 일반 Lua 검사기로 대체하지 않고 Maker build 로그를 문법 검사로 사용한다. ship 단계에서 전체 회귀 테스트를 별도 실행하지 않는다.
- 멀티플레이·모바일 전체 검증은 이번 범위가 아니다.
