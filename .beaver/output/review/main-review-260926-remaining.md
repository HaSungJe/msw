# 리뷰 — 남은 로컬 변경 일괄 반영

## 대상
- main에서 이전 ship 이후 남은 8개 파일을 전부 커밋·푸시하라는 사용자 승인.
- 실행 로그 1개, 디자인 정리 당시 파일·해시 목록과 조사 자료 6개, MCP 로컬 허용 설정 1개.

## 규약 검토
- 게임 실행 코드·현재 자산·저장 키 변경 없음. 데이터 접근 smoke 대상 없음.
- JSON 파일 파싱 통과. 토큰·개인키 등 대표 비밀정보 패턴 검색 결과 없음.
- settings.local.json은 읽기 도구 2개의 허용 목록과 MCP 서버 이름만 포함한다.
- 조사 Lua는 보관 자료이며 게임 진입점에 연결하지 않는다. inspect-preview.lua의 파일 끝 빈 줄만 정리했다.
- 문법 게이트는 변경된 JSON/JSONL 파싱과 diff 공백 검사를 사용한다. 게임 행동 테스트는 수행하지 않는다.

## 판정
통과. 사용자 요청에 따라 앞서 제외했던 파일을 모두 포함한다. 민감 설정인 .mcp.json·.codex 및 .info는 변경 목록에 없으며 포함하지 않는다.

## 로드맵 및 작업 모드
신규 완료 단위는 해당 없음. 현재 버전만 이번 커밋에 맞추며 진척은 38/47, 다음 단계는 Phase 10 개인 테마와 Phase 14 아이콘이다. 직접 작업 모드라 워크트리 병합·삭제는 해당 없음.
