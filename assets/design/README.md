# 디자인 자산

현재 사용하는 원본과 진행 중인 작업만 둔다.

| 폴더 | 내용 | 상태 |
|---|---|---|
| `characters/<직업>/` | 11직업 원화·대기·스킬 프레임·흉상(비숍 기준 그림체) | 게임 적용 중 |
| `effects/` | 팬텀 조커 카드·고리 등 스킬 이펙트 원본 | 게임 적용 중 |
| `ui/` | 등급·능력치 아이콘, 둥근 패널 등 UI 원본(`resources.json`) | 게임 적용 중 |
| `mobile-ui/` | PC·모바일 라이트·다크 화면 시안 | 디자인 기준 |
| `themes/` | 풍경·현재 트랙·바닥 제작 원본·마을 장식 | 게임 적용 중 |
| `tombstone/` | 기본 비석 | 게임 적용 중 |
| `monster-thumbnails/` | 몬스터·보스 아이콘과 ID 대응표 | 게임 적용 중 |
